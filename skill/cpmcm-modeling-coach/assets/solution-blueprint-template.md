### 图表证据契约

| 图表 | 拟支持主张/证据角色 | 源结果工件与字段 | 样本/情景单位、统计口径与数据变换 | 图库模板与验证状态 | 生成脚本与输出 | 关键断言与视觉检查 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

图表选择按 `references/advanced-visualization.md` 执行。图库预览只用于选型；正式图必须完整替换合成数据，并从当前结果资产重建。

### 参考文献覆盖与代码交付

- 完整论文默认参考文献不少于15篇，覆盖领域、核心方法、评价、数据/标准和软件来源；官方要求优先。
- 完整源代码位于论文PDF之外；PDF附录只列文件、入口、依赖、输入输出和复现步骤。
- 使用 `paper-quality-gate-template.md` 登记引用覆盖、正文页数、图表排布、源码与工件对应关系。
