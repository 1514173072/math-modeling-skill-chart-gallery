# 高级图表选择与证据协议

## 1. 定位与入口

图表不是装饰层，而是结果证据的呈现层。只有在问题契约、结果资产 Schema 和拟支持的正文主张已经明确后才选图，不允许先选一张高级图再倒推要生成什么数据。

若当前环境包含本仓库的高级图表库，智能体应在仓库根目录查找 `chart-gallery/library`，也可以按关键词直接检索其中的Markdown文件。Windows用户可通过 Release 中的 `MathModelingChartGallery.exe` 浏览并复制模板代码。图库与Skill并列存放，不复制进Skill；移动资源包时应保持图库内部结构不变。

优先复用“验证状态=已验证”且数据契约与当前结果资产一致的模板；不能只因图形漂亮或名称相近就套用。若目录不存在或EXE不可运行，按本协议自行绘图并在审计中标明“未使用外部图表模板”。EXE只是本地浏览器，不连接AI；查询与浏览不会自动修改论文或Skill。

## 2. 选图次序

按以下顺序决策：

1. 写清要支持的主张：比较、分布、预测、校准、聚类、空间格局、优化权衡、约束可行性、尾部风险或模型解释。
2. 定位机器可读结果资产及字段，确认样本单位、分组、单位、方向、时间/空间尺度和不确定性。
3. 用数据类型、方法类型和关键词查询图库，读取候选条目的说明、数据契约和限制。
4. 选择信息量足够且最简单的图。普通点线图能够清楚回答问题时，不为“高级感”升级为三维、双轴、雷达或复杂组合图。
5. 将模板中的合成数据完整替换为真实结果资产；保留适用于当前任务的统计定义，删除与当前证据无关的示例标注。
6. 运行脚本、核对源结果字段、渲染检查并写入图表证据契约。

## 3. 方法—证据角色路由

| 证据角色 | 首选图形 | 使用门槛 |
|---|---|---|
| 多模型整体误差 | ECDF、逐折点区间、残差诊断 | 同一评价样本、同一误差定义 |
| 概率是否可信 | 校准曲线 + 概率分布 | 二元标签、样本外概率、保留分箱样本量 |
| 降维与变量解释 | PCA得分—载荷双标图 | 标准化规则明确；前两维解释率可接受或明确局限 |
| 聚类结构 | 聚类树 + 簇中心画像 | 距离、连接法、切树规则和稳定性可追溯 |
| 双目标优化 | Pareto前沿 + 折中点 | 目标方向一致；非支配判定和折中规则明确 |
| 二维连续寻优 | 响应面 + 真实迭代路径 | 有目标网格和真实迭代日志，不伪造路径 |
| 多指标方案权衡 | 平行坐标 | 指标统一同向标准化，轴顺序固定 |
| 硬约束解释 | 可行域 + 目标等值线 + 求解点 | 仅适用于二维或明确高维切片；全部硬约束在图中/图注可追溯 |
| 随机优化与风险 | VaR/CVaR + 违反概率 | 足量独立情景、置信水平和允许违反率预先声明 |
| 调度与资源 | 甘特图 + 资源占用 | 时间区间来自真实解；容量、前置关系另行断言 |
| 空间效应 | 热点/冷点 + 不确定性 | 合法边界、投影、邻接权重、显著性校正可追溯 |
| PDE连续场 | 场图 + 关键截面/时间曲线 + 误差或残差 | 网格、单位、色标一致；至少有收敛/残差证据，三维曲面不单独充当精度证明 |
| 空间路径体验 | 合法游线叠加 + 沿程感知曲线 | 路线坐标不穿障；采样距离、可见性/开合定义和关键位置可复算 |
| 加性模型解释 | 累积归因决策路径 | 基线+贡献和=预测；不得解释为因果效应 |

## 4. 图表证据契约

每张正文主图在 `solution-blueprint-template.md` 中登记：

- 正文要支持的主张和图的证据角色；
- 源结果工件、字段、样本/情景单位、统计口径和生成脚本；
- 采用的图库条目及其验证状态；
- 从结果字段到绘图数据的全部变换，包括过滤、聚合、标准化、分箱、排序和不确定性计算；
- 关键数值断言，例如终点等于基线加贡献和、Pareto点确为非支配、甘特任务不超容量；
- 输出文件、生成时间与视觉检查状态。

图库 PNG 只是合成示例预览，不是论文证据；图库 Markdown 中的合成数据禁止进入正式论文。图表代码运行成功只证明工程可执行，不能证明统计口径和科学结论正确。

## 5. 禁止和降级

- 没有真实结果资产时，不生成带真实语气的数值图；可以输出“待生成图表清单”和所需 Schema。
- 没有迭代日志时，不画优化路径；只有最终解时只标最终解。
- 没有空间权重、显著性或边界来源时，不声称热点/冷点显著。
- 加性归因、特征重要性和预测贡献不写成干预效应。
- 两个目标的投影不能代表高维完整 Pareto 前沿；二维可行域不能代表未展示维度。
- 双轴、三维、雷达、桑基和复杂组合图只有在信息结构确实需要时使用。
- 图中文字、单位、图例、色标、样本量和不确定性缺失时，不进入最终论文。

## 6. 验收

每张主图至少通过四层检查：源结果字段存在；绘图数据可重算；绘图脚本生成预期文件；渲染后无裁切、遮挡、乱码或误导性尺度。正文引用的极值、比例、排序和阈值从源字段重新计算，不从 PNG 目测抄写。结果资产变化后必须重新生成图表并重新运行关键断言。

正文排布同时执行 `paper-quality-gates.md`：图表先被正文引用，再由正文解释；不连续堆叠三张以上互不构成同一比较任务的图表；同一结果的图和表若无不同证据角色则保留一种。最终PDF逐页视觉检查是硬门，文件存在、HTML `img` 数量或PDF图片对象数量只能作结构检查，不能证明可读性。
