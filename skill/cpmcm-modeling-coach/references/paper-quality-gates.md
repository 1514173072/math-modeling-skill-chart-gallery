# 竞赛论文统一质量门

用于完整竞赛论文的通用结构、篇幅、语言、图表、引用和代码交付。赛题与当届官方格式始终优先；官方未规定时才采用本文件默认值。

## 1. 竞赛背景与读者

任务简报开头明确：当前任务是数学建模竞赛，用户是参赛者或参赛队，目标读者是竞赛评委。论文优先回答题目、展示证据和方便复核，不写成课程教材、商业报告或模型宣传稿。新题启动仍必须通过 `preflight-and-data-semantics.md` 的硬暂停门；背景声明不能替代用户确认。

## 2. 通用章节最低标准

- **摘要**：原则上一页内完成。按小问写清任务、方法及理由、关键定量结果、验证和边界；不放图表、公式、引用和算法名清单，不出现正文没有的结果。末尾给3—5个能区分题目与方法的关键词。
- **问题重述**：重组题目的输入、输出、约束和小问依赖，不复制题面长段落，不改变目标，不提前写结果。
- **问题分析**：给出每问的信息流、主要困难、透明基线、主方法选择理由和跨问接口；不把算法简介当分析。
- **模型假设**：每条写明内容、题面/数据依据、对结论的影响和可检验或敏感性方式。不能用假设取消硬约束或掩盖缺失数据。
- **符号说明**：只列正文实际使用的符号，统一单位、索引和向量/矩阵字体；首次出现仍要就地解释。
- **逐问建模**：按“问题契约 → 数据/机理 → 基线 → 主模型 → 求解 → 结果 → 验证 → 局限”形成闭环；没有证据的环节如实标缺失，不用通用算法教程补齐。
- **模型评价与结论**：优点必须对应已完成证据，缺点写明影响和升级条件；预测、关联、模型情景、现实干预分别命名。

## 3. 篇幅状态机

正文页数只统计摘要起至结论/模型评价止，不含封面、目录、参考文献、附录和源代码。记录渲染后真实页码，不用字数比例估算页数。

`候选稿完成 -> 正文页数审计 -> 缺口矩阵 -> 第二轮证据型扩写 -> 重新渲染 -> 达标或暂停请示`

第一次未达用户确认目标时，使用 `assets/paper-quality-gate-template.md` 建立缺口矩阵，逐项检查题面覆盖、推导、假设依据、基线、消融、敏感性、不确定性、负结果、图表解释、跨问接口、复现信息和局限。扩写项必须满足至少一种证据来源：已有结果工件、可重算推导、真实新增实验、已核实引用或明确的限制分析。

第二轮扩写后必须重新生成最终格式并复核正文页数。仍未达到下限时，停止最终交付并向用户报告：当前正文页数、目标下限、已补内容、仍缺证据，以及两个选择——接受当前短稿，或授权新增实验/分析。不得自行降低目标，不得通过加大字号、放大图表、重复背景、拆表或粘贴代码凑页数。

## 4. 语言质量门

采用直接、可核验的竞赛论文语言：先写对象和动作，再写结果和边界。删除“众所周知、具有重要意义、大大提高、效果显著、先进、完美、最优”等无比较或无证据修饰。相邻段落不得重复同一结论；变量、模型和指标首次定义后保持同名。每个定量判断同时交代比较对象、样本/情景、指标和不确定性。

交付前专项搜索残留Markdown标记、口语占位、英文界面词、模板句、未定义缩写和过长复句。语言润色不得改变数值、方向、统计显著性或证据等级。

## 5. 图表排布与引用

- 图表必须先在正文中被引用，再紧邻出现，并由后续文字解释“看到了什么、支持哪项主张、有什么限制”。
- 不连续堆叠三张以上图表。若两张以上必须连续，需共享同一比较任务并合并为有清晰子图标签的组合图；否则在其间加入实质分析或移至支撑材料。
- 同一结果的图和表不重复占正文，除非二者承担不同证据角色并明确说明。大而密的全量结果表放支撑材料，正文保留回答题目的摘要表。
- 图题、表题独立交代对象、样本/情景、单位、指标和统计口径。图例、色标、轴标签、注释和正文方向一致。
- 最终PDF逐页视觉检查裁切、遮挡、跨页、孤立标题、字号、灰度可辨性和图文对应；仅检查HTML标签数或PDF对象数不能代替视觉检查。

## 6. 代码交付边界

完整源代码默认不进入论文PDF。正文只放公式、流程图、与公式对应的必要伪代码和关键参数；附录只列源码文件清单、运行入口、依赖、输入输出和复现步骤。完整代码以独立源码目录交付，并与正式结果工件逐一对应。

临时命令生成但没有正式脚本负责的工件视为无主工件，不能进入最终论文。主表和正文关键数字应从机器可读结果程序化生成，不能人工抄写。

## 7. 参考文献覆盖门

完整论文默认不少于15篇真实且正文实际使用的参考文献，并覆盖：题目领域背景、核心模型原始或权威来源、评价/检验方法、数据或标准来源、关键软件/算法实现。官方格式、篇幅或题目性质要求不同时按官方规则调整，并记录原因。

使用 `assets/paper-quality-gate-template.md` 建立引用覆盖表。每篇来源至少在正文承担一个明确作用；不得把未阅读、无法定位、正文未引用或与主张无关的来源用于凑数。网络来源优先官方、标准、论文或软件文档；关键领域事实和方法定义不能只引用聚合网页。
