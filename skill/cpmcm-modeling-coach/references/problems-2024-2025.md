# 2024—2025 年中国研究生数学建模竞赛题目地图

本参考基于本地完整题面逐题整理，供选题、方案设计和优秀论文精读时调用。它不是标准答案，也不意味着列出的方法必然有效。优先级综合考虑用户现有背景（应用统计、多变量时间序列、非线性动力系统、RC/CCM/RCM、因果机器学习、复杂网络、预测、机器学习、文本分析与调度）及方法成长价值：`P0` 优先精读，`P1` 第二梯队，`P2` 专业门槛较高或迁移收益较低。

## 2024-A 风电场有功功率优化分配

- **输入**：100 台风机的塔架推力、主轴扭矩及雨流计数参考损伤；轮毂风速、有功功率参考值与载荷；电网调度时序；另有含正负 10% 测量噪声和最长 10 秒通信延迟的数据。
- **任务链**：构造不使用机器学习、CPU 计算小于 1 秒的在线疲劳损伤指标 → 由风速和功率估计塔架推力与主轴扭矩 → 每秒为 100 台风机进行双疲劳目标的有功功率优化分配 → 在噪声和延迟下形成鲁棒方案。
- **适用方法**：在线转折点或能量增量型疲劳代理、Palmgren–Miner/雨流基准对照、物理约束非线性回归、多目标凸优化或序列二次规划、模型预测控制、卡尔曼滤波、延迟补偿、情景或分布鲁棒优化。
- **关键验证**：逐秒损伤曲线与雨流参考的趋势一致性；全部样本覆盖而非少量示例；载荷估计误差；每次优化的真实计时；功率总和、额定功率和相对平均分配偏差等约束逐时满足；与平均分配比较累计损伤、公平性和最坏风机；噪声/延迟压力测试。
- **更正/缺陷与边界**：题面数据均为风速超过额定风速的风能过剩场景，外推到全工况需谨慎；短窗口代理不等于全寿命疲劳；带噪测试集没有无噪真值；仿真优化有效不等于真实风场干预效果成立。
- **与用户背景**：高度连接多变量时序、非线性动力系统、预测—优化闭环与鲁棒决策；RC 可作快速状态/载荷预测器，但不得把预测模型写成因果模型。
- **优先级**：`P0`。

## 2024-B WLAN 组网中网络吞吐量建模

- **输入**：2 或 3 个同频 AP 的拓扑、UDP/TCP 业务、包长、PD/ED/NAV 门限、多种节点间 RSSI，以及实测发送序列总时长 `seq_time`、MCS/NSS、PER 和吞吐量。
- **任务链**：解释并排序影响 AP 发送机会的因素 → 预测 AP 发送时长 → 预测最常用的 MCS/NSS → 综合发送机会和物理速率预测每 AP 与系统吞吐量。
- **适用方法**：按 PD/ED/NAV 门限划分同步、异步和互不侦听状态；构造拓扑/图特征与 SINR 特征；混合效应回归、GAM、GBDT、序数分类；机制公式加机器学习残差校正。
- **关键验证**：按位置、拓扑或测试批次分组验证；分别报告 2AP/3AP、单 AP/系统吞吐；按题面要求用误差 CDF 的 90% 分位评价；检查因素排序对重采样和模型选择是否稳定；与纯机制、纯黑箱基线比较。
- **更正/缺陷与边界**：RSSI 是大尺度统计，不能完整反映快速信道变化；聚合测试记录不是连续动力系统轨迹；特征重要性不等于因果效应；随机行切分容易泄漏相同位置或拓扑。
- **与用户背景**：连接可解释预测、复杂网络和多变量建模；与 CCM/RCM 的动力学方向识别仅弱相关，不宜硬套。
- **优先级**：`P1`。

## 2024-C 数据驱动下磁性元件的磁芯损耗建模

- **输入**：4 种材料、4 档温度、50—500 kHz 频率、正弦/三角/梯形励磁波形、每周期 1024 点磁通密度序列和磁芯损耗。
- **任务链**：波形分类 → 为 Steinmetz 方程加入温度修正 → 分析温度、波形、材料的主效应及两两交互 → 建立跨材料和工况的损耗预测模型 → 同时优化磁芯损耗与传输磁能。
- **适用方法**：磁通密度的导数、谐波、峰度和形状特征；非线性参数拟合；ANOVA、GAM、响应面；物理启发特征结合 GBDT/随机森林/神经网络；分组交叉验证；Pareto 多目标优化。
- **关键验证**：按材料、温度或工况分组而非随机行切分；修正方程与原 Steinmetz 方程同口径比较；报告交互效应置信区间与稳健性；预测模型做跨材料/跨工况测试；输出 Pareto 前沿而非武断给出唯一最优点。
- **已知更正**：2024-09-21 专家委员会更正两处：第八页“系数与公式（5）的系数”应为“系数与公式（2）的系数”；“如式（8）、（9）所示”应为“如式（9）、（10）所示”。
- **缺陷与边界**：相似波形随机切分会产生泄漏；SHAP 或 ANOVA 关联不自动等于物理因果；附件变量覆盖范围限制外推。
- **与用户背景**：高度连接应用统计、非线性回归、时序形状特征、机器学习和多目标优化。
- **优先级**：`P1`。

## 2024-D 大数据驱动的地理综合问题

- **输入**：中国 DEM、1979—2018 气温、1961—2022 日降水、1900—2019 土地利用/覆被、1990—2015 人口和 GDP 等多尺度 GeoTIFF/NetCDF 栅格数据。
- **任务链**：用 1—3 个简洁指标或图表概括 1990—2020 降水与土地覆被演化 → 建模地形—气候相互作用对极端天气的作用 → 确定暴雨成灾临界条件并预测 2025—2035 脆弱区 → 提炼中国土地利用变化的总体结构并验证其准确性与有用性。
- **适用方法**：重投影和尺度统一、时空趋势与变点、POT/GEV 极值理论、空间 GAM/面板模型、地形交互项、空间自相关、PCA/聚类、暴露—敏感性—适应能力脆弱性框架、不确定性地图。
- **关键验证**：空间分块或留区域交叉验证；不同栅格尺度和时间窗口的敏感性；极端阈值的重现期/超越概率校准；历史回测脆弱区；人口、GDP和土地利用不同时间终点的口径审计；地图同时呈现预测和不确定性。
- **更正/缺陷与边界**：本地题面未见公开更正；各数据集时间范围不一致，人口和 GDP 仅到 2015；题面缺少完整灾损标签，严格识别“成灾阈值”困难；地形—气候统计关联不等于干预因果；2035 结果高度依赖外推假设。
- **与用户背景**：连接应用统计、多变量时空序列、复杂系统和因果机器学习的识别边界，能补足 GIS 与空间统计。
- **优先级**：`P0`。

## 2024-E 高速公路应急车道紧急启用模型

- **输入**：约 5000 m、2 条行车道加 1 条应急车道的路段，以及 4 个固定视频观测点的交通视频。
- **任务链**：从视频提取流量、密度、速度的细粒度时序 → 对第三至第四观测点间持续拥堵进行实时提前预警 → 用视频验证 → 设计应急车道启停决策并量化作用 → 优化监控点布设。
- **适用方法**：车辆检测跟踪与视频标定、交通基本图、LWR/CTM、隐状态或变点检测、时序分类/生存分析、滚动预警、仿真反事实、MPC、基于可观测性或信息增益的传感器选址。
- **关键验证**：车辆计数、速度和密度先对人工标注验证；严格滚动时间回测并防止未来信息泄漏；报告预警提前量、召回率、误报率和持续时间；用守恒关系检查四点交通流；在可比需求下仿真“不开/开启”反事实；分析检测误差向决策传播。
- **更正/缺陷与边界**：本地题面未见公开更正；四个点不能直接观测路段内部完整状态；数据中通常缺少真实开启应急车道的处理样本，作用量多为仿真估计；事故场景明确不属于主要建模范围。
- **与用户背景**：高度连接视频数据、时间序列、状态空间、预测—决策闭环和因果反事实边界。
- **优先级**：`P0`。

## 2024-F X 射线脉冲星光子到达时间建模

- **输入**：XPNAV-1 卫星六轨道根数、太阳系天体 DE 历表、Crab 脉冲星位置与自行、自转参数、标准脉冲轮廓和光子流量参数；本地另有完整题目附录。
- **任务链**：由轨道根数计算 GCRS 位置与速度 → 计算航天器到太阳系质心的真空几何时延 → 加入自行、Shapiro 时延、引力红移和动钟变慢得到精确时延 → 建立非齐次泊松光子序列并进行周期折叠。
- **适用方法**：开普勒轨道转换、GCRS/BCRS 坐标与 TT/TDB/TCB 时间尺度变换、相对论时延项、JPL DE 历表调用、非齐次泊松过程 thinning 或逆变换、周期折叠、Monte Carlo 误差传播。
- **关键验证**：轨道六根数的回代一致性；位置、速度、时延的单位和数量级检查；与成熟星历/计时软件或独立公式交叉核对；逐项报告时延贡献；多随机种子验证光子计数、相位分布和折叠轮廓；做时间尺度和历表版本敏感性分析。
- **更正/缺陷与边界**：本地题面未见公开更正；必须连同附录读取，正文文本抽取会丢失部分公式符号；坐标系、时间尺度或单位稍有混用即可造成数量级错误；仿真轮廓吻合仅证明模型自洽，不证明真实导航精度。
- **与用户背景**：连接点过程、周期时序和动力系统，但轨道力学、天体测量和相对论前置知识较重。
- **优先级**：`P2`。

## 2025-A 通用神经网络处理器下的核内调度问题

- **输入**：包含操作节点、ALLOC/FREE 缓存节点及依赖边的 DAG；节点给出执行单元、周期、BufId、Size 和缓存类型；另给 L1/UB/L0 容量、地址复用和 SPILL 规则。
- **任务链**：寻找最大缓存驻留量尽可能小的合法拓扑序 → 分配连续物理地址并插入尽量少的换入换出 → 在额外搬运量不显著增加时降低总执行时间，或联合优化两项指标。
- **适用方法**：DAG 列表调度、关键路径与内存释放启发式、寄存器分配/区间分配、best-fit 与碎片控制、pebble-game 思想、beam search、整数规划小图基准、局部搜索和 Pareto 优化。
- **关键验证**：拓扑合法性、ALLOC/FREE 生命周期和地址无重叠；L0A/B/C 各最多一个缓冲区驻留；SPILL 节点和新增依赖完整；按题面模拟器重算最大驻留、额外搬运量与总周期；小图与精确解比较；报告复杂度、运行时间和启发式消融。
- **更正/缺陷与边界**：本地题面未见公开更正；多个子问题具有组合优化难度，示例图上的最优或近优不代表可推广；性能结论依赖题面规定的架构抽象和评估器，不等同于真实芯片端性能。
- **与用户背景**：连接调度、多目标优化和复杂网络，能显著补足算法工程，但与当前时序因果主线直接联系较弱。
- **优先级**：`P1`。

## 2025-B 无线通信系统链路速率建模

- **输入**：每个样本的 `2×4×122` 复数 CSI、noise floor、CSI/速率时间戳、TxBF 开关、终端标识和 MCS 标签；训练集标签完备，验证集无标签。
- **任务链**：在关闭 TxBF 时计算各子载波 SINR、拟合 EESM 并预测速率索引 → 提出优于 EESM 的关闭 TxBF 模型 → 为开启 TxBF 的场景建立新模型。
- **适用方法**：每子载波奇异值和 SINR、EESM 参数拟合、CSI 谱特征和频域平滑、序数分类、物理特征结合 GBDT/MLP/1D-CNN、按终端或移动位置分组建模。
- **关键验证**：CSI 与 MCS 时间对齐；关闭/开启 TxBF 分开评价；按终端、位置或连续采集段分组验证；与 EESM 和简单序数基线比较；混淆矩阵、相邻等级误差和校准；对噪声底、载波缺失和时间错配做敏感性分析。
- **更正/缺陷与边界**：本地题面未见公开更正；MCS 是离散速率索引而非实际吞吐量；相邻时间和同位置样本高度相关，随机行切分会泄漏；若 TxBF 权值信息不完整，物理模型能力受限。
- **与用户背景**：连接高维复数时序、降维和机器学习预测；适合训练“物理层基线 + 数据驱动修正”的建模习惯。
- **优先级**：`P1`。

## 2025-C 围岩裂隙精准识别与三维模型重构

- **输入**：钻孔成像展开图、正弦状与复杂裂隙图像、统一钻孔直径和图像坐标；6 个钻孔的空间位置、深度及长条展开图。
- **任务链**：在纹理、钻痕和泥浆干扰下分割裂隙像素 → 对正弦状裂隙自动聚类并拟合振幅、周期、相位和中心线 → 表征复杂裂隙并计算 JRC → 估计相邻钻孔裂隙连通概率、三维重构、识别高不确定区并推荐 3 个补充钻孔。
- **适用方法**：纹理/形态学与 U-Net 对照、周期边界感知分割、连通组件、RANSAC/Hough/DBSCAN、鲁棒正弦拟合、自适应曲率采样、概率图模型或裂隙网络、贝叶斯连通性、信息增益选址。
- **关键验证**：像素级 IoU/F1 与干扰类型分层评价；正弦参数的重投影误差和边界连续性；JRC 对采样密度/策略的敏感性；连通性以几何一致性和多方案稳定性验证；三维结果必须携带概率或不确定性；补孔方案用预期不确定性下降衡量。
- **更正/缺陷与边界**：本地题面未见公开更正；二维钻孔交线不能唯一确定三维裂隙面；JRC 对离散点选择敏感；缺少完整连通真值；分割和拟合误差会层层传递，漂亮的三维图不等于地质结构正确。
- **与用户背景**：连接图像分析、复杂网络、概率重构和主动采样，能补足不确定性传播与空间建模。
- **优先级**：`P0`。

## 2025-D 低空湍流监测及最优航路规划

- **输入**：风廓线雷达、微波辐射计、1 部 S 波段和 3 部 X 波段天气雷达、100 多个地面站；3 小时多源观测、6 小时数值天气预报和地理信息。
- **任务链**：由风廓线与微波辐射计建立相对可靠模型 a → 蒸馏为仅用风廓线、融合时空维度的模型 b → 融合异构观测生成水平 100 m、垂直 50 m、2 km 以下三维湍流场 c → 用 c 校准数值预报模型 d 并预测 05—08 时 → 在无数值预报时用非线性模型 e 外推 05—06 时 → 规划低湍流风险航路。
- **适用方法**：Richardson 数、TKE、涡旋耗散率等物理指标；时空插值/克里金、分层贝叶斯或集合融合、多源网格化、NWP 偏差订正、ConvLSTM/图时空网络/RC-ESN、集合不确定性、A*/Dijkstra/风险约束路径规划。
- **关键验证**：模型 a 与 b 的高度—时间廓线对照；按设备、时间和空间留出验证；统一时空分辨率并显式记录插值支撑范围；模型 c/d 在 02—05 时比较，05—08 时只做真正外推；模型 e 采用滚动起点回测；航路同时验证可行域、长度、最大/累计风险及对不确定性的敏感性。
- **更正/缺陷与边界**：本地题面未见公开更正；模型 a 只是相对成熟的代理标准，不是真实湍流真值；3 小时观测不足以支撑复杂深度模型的普遍泛化；RC 可用于预测但不是因果模型；CCM/RCM 只有在长度、平稳性和动力学条件满足时才可作观测方向探索。
- **与用户背景**：与多变量时空序列、非线性动力系统、RC、预测—优化和复杂网络最贴合，是两年首选精读题。
- **优先级**：`P0`。

## 2025-E 高速列车轴承智能故障诊断问题

- **输入**：161 个有标签试验台轴承文件，含 12/48 kHz 采样、不同载荷和故障尺寸；16 个无标签列车轴承文件，32 kHz、约 600 rpm；类别为外圈、内圈、滚动体故障和正常。
- **任务链**：面向目标域筛选源域数据并提取机理特征 → 建立和评价源域分类器 → 无监督迁移至目标域并为 16 个文件标注 → 解释模型结构、迁移过程或最终决策。
- **适用方法**：包络谱、阶次跟踪、时频图和故障特征频率；按文件分组的传统分类器/CNN；CORAL、MMD、DANN、类条件对齐、实例加权、伪标签与一致性学习；SHAP、Grad-CAM、频带归因和域差异诊断。
- **关键验证**：窗口必须按原始文件分组切分；处理采样率、转速、传感器位置和类别不平衡；源域报告分组交叉验证；迁移前后比较域差异、预测稳定性和机理频带一致性；多种迁移方法和随机种子一致性；主动检查负迁移。
- **更正/缺陷与边界**：本地题面未见公开更正；目标域只有 16 个文件且无标签，无法直接报告真实准确率；源域正常样本极少；t-SNE 分离、伪标签稳定或置信度高都不等于目标标签正确。
- **与用户背景**：高度连接多变量时间序列、信号处理、机器学习、迁移学习和可解释性，是现有技能最易快速形成竞赛成果的题之一。
- **优先级**：`P0`。

## 2025-F 江南古典园林的美学特征建模

- **输入**：10 个代表园林的 JPG/DWG/PDF 平面图、半开放建筑/实体建筑/道路/山石/水体/植物坐标、照片和视频；另给 10 个外部验证园林平面图。
- **任务链**：将入口到出口游线转化为图问题并量化“移步异景”趣味性 → 根据元素布局和开合转换量化“小中见大”幻境感，以寄畅园为 100 分排序 → 综合多模态数据建立园林相似度并外部验证 → 补充其他重要美学维度。
- **适用方法**：先按 `spatial-perception-multimodal.md` 完成矢量线段解析、障碍/半开放结构区分和几何拓扑修补；再用路网图、骨架/Voronoi/Delaunay候选连接、转折/岔路/覆盖率、视域变化、空间句法、景观序列熵、元素多样性与开合状态序列、Ripley K/最近邻/分形维数、图核/最优传输和多模态嵌入。游线可比较MILP、动态规划、A*与多目标启发式，但需保留最短合法路线基线；AHP/TOPSIS仅作透明权重辅助。
- **关键验证**：路线无穿墙/水体且入口出口连通，独立复算覆盖率与重复率；指标对栅格、路径采样、几何修补和元素缺失敏感性；将“趣味性/幻境感”拆成可解释子指标并用照片、视频、专家或游客评分验证；在未参与选模的附件11或其他园林做真正外部测试；相似度需通过最近邻、反例、块级消融和方法替换解释。
- **更正/缺陷与边界**：本地题面未见公开更正；“趣味性”“幻境感”是缺少可靠真值的潜变量；寄畅园固定 100 分是规范性锚点而非实证金标准；照片采样不统一且题面明确提示不可过度解读；复杂指标不能替代构念效度。
- **与用户背景**：连接复杂网络、多模态数据、文本/图像分析和可解释评价，适合拓展人文计算，但主观构念验证难度较高。
- **优先级**：`P1`。
