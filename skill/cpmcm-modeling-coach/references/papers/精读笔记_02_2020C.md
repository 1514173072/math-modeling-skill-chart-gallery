## 逐小问模型链

1. 问题一：0.1-20 Hz、46阶Butterworth IIR滤波 -> 从每次闪烁起截取125点 -> 随机抽取负样本与正样本平衡 -> 随机森林判断每个行列是否出现P300 -> 五轮投票定位字符（PDF pp.7-13）。作者用题目公开的`char13-char17`真值评价25个字符中的23个正确，报告字符准确率92%；这不是对`char18-char22`未知目标的独立评价。
2. 问题二：把20通道值作为字典，以P300标签做线性回归 -> spike-and-slab先验 -> EP近似各通道非零后验概率 -> 每名被试选择通道，再以五人中至少三人选择的多数规则得到13个公共通道 -> 重新训练随机森林（pp.14-20）。公共组合为Fz、F3、F4、C3、Cz、C4、CP3、CP4、CP5、CP6、P3、P4、P7；重新评价仍使用公开的前五个测试字符。
3. 问题三：在上述13通道上，以10个字符构成训练集，其中前30%作为有标签样本、后70%作为无标签样本，另2个字符作为验证 -> 约束正负比例`r=1/5`的S3VM与退火增加未标记样本权重 -> 预测`char13-char22`（pp.21-26）。摘要报告验证准确率75.3%，正文却报告67.3%，内部矛盾未解释；正文表6-1和表6-2对`char13-char17`的预测也不一致。
4. 问题四：五类睡眠的四维频带能量特征 -> SVM、LightGBM与随机森林 -> 对不同训练/测试比例各随机重复5次，据最高测试准确率选择比例 -> 报告LGBM/RF 89%、SVM 84%（pp.26-33）。该流程把测试表现用于选择训练比例和模型，不能视为最终泛化评价。

## 数据单位、切分与验证

- P300的基础样本是同一字符、同一轮次内的行/列闪烁后125点切片；相邻闪烁间隔约40点，因此125点窗口会发生时间重叠（pp.7-10）。正文没有按字符、轮次或被试分组的训练/验证划分，同源切片的相关性会高估普通随机切分性能。
- 问题一附录先在完整`train_data`上拟合`StandardScaler`，再调用无`random_state`的`train_test_split`，存在预处理跨越内部测试集且结果不可稳定复核；对正式待预测数据又单独拟合一个新Scaler，使训练与推理尺度不一致（pp.36-37）。
- 92%来自题目已经给出标签的`char13-char17`，未对未知`char18-char22`提供可检验真值；随机森林与KNN的比较没有独立验证集、置信区间或多随机种子协议（pp.12-14）。
- 问题二的通道选择用所有被试数据拟合后，再在相同公开测试字符上报告92%；没有外层字符/被试留出，也没有证明通道数或多数阈值在训练数据内确定（pp.18-20）。
- 问题三将同一批字符中的闪烁切片按“前30%/后70%”分为有标签和无标签，而剩余两个字符作验证；无标签样本不是独立数据源。C由交叉验证选择，但未说明这一步是否只在有标签训练字符内部完成（pp.24-25）。
- 睡眠部分正文称“交叉验证”，附录实际对五个类别分别调用`train_test_split(test_size=0.3)`后拼接，只是一轮分层近似的随机留出；无固定种子。正文又扫描多种测试比例并选取峰值，测试集承担了选模职责（pp.28-33、41-42）。

## 关键参数与作者报告结果

- 滤波器：采样率250 Hz，通带0.2-20 Hz、阻带0.1/30 Hz、阻带衰减80 dB、通带纹波1 dB；正文概括为0.1-20 Hz的46阶Butterworth IIR（pp.7、35）。正文与附录的通带下界表述并不完全相同。
- P300窗口125点即500 ms，闪烁与间隔各80 ms；每轮12个行列刺激，正类约1/6，作者通过每轮抽取两个负行列实现1:1训练平衡（pp.8、10）。
- 问题一作者报告RF对公开的25个前五字符23个正确即92%，KNN为80%，运行时间分别0.1730 s和0.0529 s（pp.13-14）。
- 问题三固定有标签900、无标签2100，`r=1/5`，采用高斯核和四步退火；正文67.3%与摘要75.3%冲突（pp.2、22、24-25）。
- 睡眠模型作者据测试曲线选择SVM 65%训练/35%测试，报告84%；LightGBM/RF在30%测试比例均报告89%，表7-2运行时间为0.0193/0.0210/0.0229 s（pp.29、31-33）。这些数值均未复现。

## 正文—附录—代码一致性

- 随机森林附录只实现S1，且创建`train_data`为720行，却按12个字符×66事件最多写入792行，数组尺寸与循环上界不一致；其他四名被试和KNN对照未给出（pp.36-37）。
- 训练数据在切分前标准化，预测数据则另行`fit`，违反统一变换契约；`train_test_split`未给分层、比例和随机种子（pp.36-37）。
- EP代码依赖未定义的`max_itt`、`MINIMUM_VARIANCE`、`MAXIMUM_VARIANCE`、`bound_values`、`log_npdf`和`fc`，并混用`Y`与`y`；PDF中还出现弯引号，当前附录不是可直接运行的完整实现（pp.38-41）。
- 正文样本有13通道×125点，却写成`10*75`向量；S3VM完整代码没有进入附录，无法核对退火、标签平衡与验证实现（p.24，pp.35-43）。
- 睡眠代码缺少LightGBM导入，`params`中`num_class`后缺逗号，且混用未定义的`X_train/y_train/X_test/y_test/test_x`；把测试集`lgb_eval`直接用于早停，再在同一`test_x`预测（pp.41-43）。
- 正文称每个训练比例重复5轮，比较运行时间又称10轮；附录只展示固定30%留出的一次脚本，没有比例扫描、重复汇总或计时代码（pp.31-33、41-43）。
