## 输入 -> 机制 -> 中间判断 -> 输出 -> 局限

A、B、C站逐小时监测/气象数据及一次预报 -> AQI计算、KNN插补与相关分析，BiLSTM-MLP进行逐日预测，正文再引入站点对抗表示与时空注意 -> 比较单站、跨站和联合建模的误差 -> 三日六污染物、AQI及多站点预测 -> 随机重叠窗口、全序列标准化和测试集选模使误差偏乐观；正文的GAN与PGAN核心链条均没有被附录完整实现。

## 逐小问模型链

1. 问题一：检查缺失和异常值，以3σ与箱线图识别异常；计算O3最大8小时滑动平均，再按IAQI分段插值计算AQI和首要污染物（PDF pp.9-17）。
2. 问题二：对缺失值比较删除、均值/中位数、回归与KNN插补，最终采用KNN；用Pearson系数和趋势图讨论气象因素与污染物的关联，并使用PCA和多元线性回归做补充分析（pp.18-27）。这些是关联分析，不是气象干预效应。
3. 问题三：将历史污染物、日历和气象特征输入双层BiLSTM与MLP，多输出预测下一日六污染物；用滚动方式生成未来三日。正文进一步加入站点判别器和对抗损失，提出GAN-Stacked-BiLSTM-MLP以剥离站点特性，宣称模型可在A、B、C站通用（pp.28-39）。
4. 问题四：正文先由站点经纬度距离构造加权邻接关系，再以空间注意、时间注意、门控融合和编码器—解码器组成所谓PGAN，联合预测多个站点（pp.40-46）。附录函数和结构实际更接近GMAN，且仅提供网络片段。

## 数据处理、切分与验证

- 正文将数据按80%训练、20%测试，并明确“经过多次训练和调参，选取测试集上效果最好的参数”（p.35）。这等于用测试集选模；没有独立验证集，最终指标不能视为一次性的独立泛化评价。
- 问题三代码先对完整序列插补，再以完整序列均值和标准差归一化，之后生成长度8的重叠窗口，最后调用`train_test_split(..., random_state=42)`随机划分窗口（pp.55-56）。因此至少存在两类泄漏：未来测试时段参与预处理参数估计；相邻高度重叠窗口被随机分到训练与测试两侧。
- 双向LSTM只在一个已知历史窗口内部正反向编码；只要窗口不包含预测时点之后的信息，双向结构本身不必然构成未来泄漏。本文真正严重的问题是全序列预处理与随机重叠窗口。
- 三日递推时，下一日输入由前一日预测污染物和`time_encodding`拼接。代码中的`time_encodding`其实取最后三行的全部剩余特征，不只是时间编码；未来气象等外生变量在业务预测时是否可得没有形成清楚的数据契约（pp.58-59）。
- 问题四同样只给80/20口径，未说明按日期连续切分；结合正文的测试集调参表述，时空模型结果也不具备可信的独立测试协议（pp.44-45）。

## 关键参数与作者报告结果

- 正文称问题三输入步长6、输出未来3日、batch size 32、学习率0.0005，并在多次训练后选择测试集表现最好的配置（p.35）。
- 附录实际以`interval=8`生成样本，即前7步预测第8步；训练batch size为16，学习率为`3e-4`，固定训练200个epoch（pp.55-59）。正文和代码的时间窗、批量大小、学习率均冲突。
- 作者表5-1报告：RNN的MAE/RMSE/R为4.76/5.32/0.69，LSTM为4.24/5.01/0.70，Stacked-BiLSTM-MLP为2.41/3.80/0.74，GAN-Stacked-BiLSTM-MLP为2.32/3.75/0.77（p.37）。同表中GAN模型的另一项MAE由2.38变为2.46，虽RMSE和R略有改善，不能概括为所有指标都全面优越。
- 作者表6-1报告PGAN的MAE/RMSE/R为1.85/3.21/0.69，并与前述模型比较（p.45）。这些结果均未重跑。
- 三日六污染物、AQI和首要污染物预测结果见问题三结果表（pp.38-39）；多站点联合预测及比较见问题四结果（pp.44-46）。

## 正文—附录—代码一致性

- 正文的GAN模型应包含站点ID、站点判别器、对抗损失以及生成器/判别器的训练规则；问题三附录只实现名为`Baseline`的双层BiLSTM+MLP，且只读取监测点A的逐日数据，没有站点标签、判别器、对抗目标或交替训练（pp.55-59）。GAN跨站点核心结果不能由附录重建。
- 附录每个epoch直接查看`test loss`，没有独立验证集、早停或明确的模型保存规则，与正文“多次训练和调参后选测试集最好参数”共同确认测试集参与选模（pp.57-59）。
- 评价代码先执行`count += len(Y)`，随后执行`mse += loss.item() * count`；这里乘的是累计样本数而非当前batch大小，最终`mse/count`并非标准样本均方误差（p.58）。
- 问题四附录只给网络函数片段；入口函数名为`GMAN`而非`PGAN`，依赖未提供的`tf_utils.conv2d`，也缺少数据装载、空间嵌入`SE`构造、训练循环、损失、超参数、评价和预测导出（pp.60-66）。代码不能直接运行，也不足以重建论文结果。
- 正文定义基于站点距离的加权邻接矩阵，但附录主体只接收预先计算的`SE`，没有邻接矩阵或空间嵌入生成过程，空间结构来源无法复核（pp.41-43、60-66）。

## 可重建程度与可复用思想

- AQI计算、KNN插补、普通BiLSTM-MLP和三日滚动预测可以按论文框架重建；但应先明确预报时点、可用的未来日历/气象信息和训练边界。
- GAN跨站点模型不可按附录重建，因为站点判别器与对抗训练完全缺失；PGAN/GMAN只留下不完整网络片段，缺数据、空间嵌入和训练评价链，也不可重建报告数值。
- 可复用的严谨协议：按日期连续切分；仅在训练段或交叉验证折内拟合插补与标准化；窗口不得跨越切分边界；使用验证集调参，测试集只评价一次；让持续性、ARIMA、ESN、普通LSTM和图时空模型共享完全相同的数据边界；按预测提前量和污染物分别报告MAE、RMSE及不确定性。
- 对用户研究方向最有价值的延伸是把ESN/RC作为低成本动态基线，与LSTM和图模型在同一滚动验证协议下比较。站点表示不变性只能解释为域泛化目标，不能自动推导污染传播因果关系，更不等同于干预效应。
