## 输入 -> 机制 -> 中间判断 -> 输出 -> 局限

100名有标签患者及58名待预测患者的基线、治疗、首次/随访影像 -> 相关性并查集筛特征、时间间隔权重、GBDT、决策树曲线、谱聚类和Stacking -> 以样本内误差、轮廓系数和声称的五折指标选模型 -> 血肿扩张概率、水肿轨迹亚组、90天mRS及临床建议 -> 附录实际在训练集拟合并评价，聚类引入未来mRS，治疗分析没有因果识别，且大部分核心流程没有完整代码。

## 逐小问模型链

1. 问题一：按48小时内绝对增量≥6 mL或相对增量≥33%标记23名扩张患者 -> 低方差过滤 -> 取Pearson/Spearman/灰色关联/NMI最大值并以阈值0.8做并查集合并 -> 时间间隔权重 -> KNN/SVC/RF/GBDT概率比较与消融（PDF pp.12-20）。作者以MAE/MSE/R²评价二分类概率，报告GBDT MAE=0.0524；没有AUC、Brier、校准或独立测试评价。
2. 问题二a/b：以全部随访检查的时间预测水肿体积，对比线性、RF、GBRT和决策树；再以患者属性做3类聚类，比较GMM/BIRCH/DBSCAN/谱聚类，并在各簇内重拟合决策树（pp.21-31）。作者报告整体决策树R²=0.9615，分簇后各簇约0.967-0.971，但附录显示这些是对拟合数据自身的预测。
3. 问题二c/d：按谱聚类得到的61/18/21人三组定义“振荡趋缓/波动平稳/振荡反复”，比较各组治疗频数并选3名患者作个案；再据相关系数0.47和个案折线宣称水肿相对血肿存在滞后，进而解释治疗效果（pp.31-38）。这是观察性描述，不能识别治疗效应或稳定时滞。
4. 问题三：对七级90天mRS做Borderline-SMOTE和五折Stacking；随后加入5个随访汇总特征；最后对预测为血肿扩张者做PCA并将高载荷变量解释为影响因素（pp.39-47）。作者报告Stacking精确率/召回率0.835/0.821，加入随访后0.923/0.894，但未说明宏/微平均、SMOTE折内顺序或外层评价。

## 数据、切分、泄漏与评价

- 问题一的特征筛选、权重函数和调参是否在每个训练折内重新拟合，正文没有可执行协议。附录实际对全部`train_x/train_y`拟合，再对同一`train_x`调用`predict_proba`计算MAE/MSE/R²（pp.16-20、54-56），所以主要概率指标是训练内表现。
- 附录定义`feature_weighting_1`但在展示的训练链中没有调用；正文核心“发病到首次影像时间权重”没有被已给代码实现（pp.14-15、53-56）。
- 水肿回归正文声称网格搜索与K折8:2验证，附录则将全部`x_training/y_training`拟合后直接在同一数据上`predict`、`score`和计算残差；R²约0.96是典型决策树训练拟合，不能作为泛化误差（pp.23-24、56-59）。
- 聚类明确使用表1全部个体属性，包括90天mRS（p.27）。mRS是未来结局，把它用于构造水肿轨迹亚组会引入结局信息，随后再以这些组解释治疗和轨迹，形成严重后验分组偏差。
- 患者有不等次数、不规则时间随访；把每条检查记录当独立点随机验证会让同一患者进入训练和验证。正文没有患者级分组折、随访选择机制或失访处理。
- 预后建模只描述五折交叉验证，未给SMOTE、标准化、特征筛选与Stacking的嵌套顺序；若Borderline-SMOTE在分折前执行，会产生合成邻近样本泄漏。附录没有该部分实现，无法核验（pp.40-45、48-59）。
- 七分类问题只给一对“精确率/召回率”汇总值，没有各类支持数、混淆矩阵数值、宏/微/加权口径、校准或外部测试标签，无法判断稀少死亡类别的表现（pp.39-45）。

## 因果与临床表述边界

- 治疗分配由病情严重程度、禁忌证和医生判断决定；论文只比较各亚组治疗频数，没有处理基线混杂、治疗时间、联合治疗、随访选择或生存者偏差。诸如“降颅压治疗有效控制”“某方案治疗效果显著”只能降级为观察性伴随描述（pp.31-38）。
- “水肿滞后于血肿”主要来自3名个案的稀疏折线，没有不规则时间滞后模型、跨患者统计检验或方向稳定性；相关系数0.47也不支持时滞方向（pp.35-37）。
- PCA只寻找预测扩张者子样本中的最大方差方向，载荷大不等于对血肿扩张或mRS有预测贡献，更不等于危险因素或干预靶点（pp.45-47）。
- 随访最大体积与持续时间发生在基线之后；它们可用于动态预后更新，但不能与“首次影像即可预测”的基线模型混为同一临床决策时点（pp.43-45）。

## 正文—附录—代码一致性

- `NMI`函数的缩进使熵与`return`位于外层类别循环中，可能只处理首个A类别；其用于连续变量也缺离散化协议。作者又把Pearson、Spearman、灰色关联和NMI四种不同量纲统计量直接取最大绝对值，阈值0.8缺统一含义（pp.13-14、49-52）。
- 并查集代码用`idx=list(set(p))`提取父节点，没有对所有节点最终路径压缩，也按任意根节点选择代表变量；保存为`the_name_2.npy`，后续却加载`the_name.npy`，文件名不一致（pp.51-53）。
- 正文表7把GBDT参数`criterion`写成`gini`，而标准GradientBoostingClassifier不使用该分类树分裂准则；附录实际实例化默认GBDT，没有表中网格搜索参数（pp.19-20、55）。
- 问题一代码注释掉正负类10%留出，最终所有分类器都在全训练集拟合/评价；Stacking也被放入此训练内比较，和正文“消融+K折”不一致（pp.54-56）。
- 水肿回归附录的大多数模型块被注释；仍运行的簇内决策树对全部簇内记录训练并自评，没有网格搜索、K折、患者分组或独立验证实现（pp.56-59）。
- 附录没有谱聚类构造、Borderline-SMOTE、mRS Stacking、五折评价、PCA或最终预测导出代码；当前PDF不能重建论文大部分核心结果。
