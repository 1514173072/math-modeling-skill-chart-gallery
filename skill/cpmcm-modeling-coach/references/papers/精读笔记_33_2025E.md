## 一句话定位

这是一篇“机理特征 + 小波/ViT → 源域分类 → DANN/MMD迁移 → SHAP解释”的完整叙事，故障频率与包络谱的物理锚点值得保留；但附录与正文存在决定性冲突：ViT头未训练、筛选几乎不筛样本，源域代码不是分层划分且样本量对不上混淆矩阵，迁移代码既不是ResNet-CBAM又没有把MMD加入优化，还使用10类分类头和8簇KMeans。目标域无标签情况下的内聚性和分布混合只能支持内部一致性，不能证明16个文件标签正确。

## 总体链条：输入 → 机制 → 中间判断 → 输出 → 局限

- 输入：江南大学600 rpm源域振动信号、16个无标签目标域`.mat`文件、轴承几何/转速参数，以及源域四类故障标签。
- 机制：下采样与重叠滑窗；SNR/RMS/峭度筛选；时域、包络频谱、CWT/DWT和故障频率分析；小波图经ViT提取128维特征；ResNet-CBAM源域分类；DANN域对抗与MMD分布对齐；KMeans/余弦距离生成伪标签；t-SNE、SHAP、TCAV和解释性指标审计。
- 中间判断：窗口质量是否合格、频谱峰是否接近BPFO/BPFI/BSF/FTF、源域模型在随机测试集表现如何、迁移后两域是否更难区分、目标文件最接近哪类源域中心、重要频点是否与故障机理一致。
- 输出：每类362个源域样本、手工与128维深度特征、源域四模型性能、16个目标文件的四类标签、MMD/内聚性/匹配度消融表和SHAP解释图。
- 局限：重叠窗口随机拆分可能造成原始记录泄漏；代码链之间输入输出不接；关键模型、类别数、训练轮次与正文不符；迁移损失实现错误；无目标真值，所谓可靠性主要是模型自洽而非外部验证。

## 逐小问模型链

### 问题一：源域筛选、故障机理与融合特征

1. 从600 rpm江南大学数据选四类状态，将原始信号下采样到32 kHz，以1024点窗口、512点步长切分。
2. 用SNR、RMS和波峰/峭度等指标给窗口评分，正文称每类保留362个高质量样本并保留10%低分样本。
3. 通过时域波形、FFT/包络谱、CWT和DWT比较正常、内圈、外圈及滚动体故障，并用BPFO、BPFI、BSF和FTF作机理锚点。
4. 提取20余个人工特征；把振动信号转为小波图，经ViT生成128维深度特征，再与人工特征融合。
5. 用t-SNE展示ViT特征四簇，并报告轮廓系数0.7755。

关键证据：筛选流程与每类362个样本见PDF pp.7—8；时域/频域/CWT-DWT图见pp.8—10；特征定义与样例表见pp.10—13；ViT、小波图和t-SNE见pp.14—15；附录预处理/ViT代码见pp.38—40。

审计判断：附录`snr_calc`把信号功率定义为`mean(sig²)`、噪声定义为`sig-mean(sig)`；对均值接近0的振动信号，分子和分母几乎相等，SNR会普遍接近0 dB，不是具有独立噪声估计的信噪比。数据集虽然记录了SNR/RMS/峭度，实际筛选只按SNR第10百分位：先保留最高90%，再从最低10%取约总样本10%，因此几乎把全部窗口重新拼回，不能产生正文所称严格质量筛选。正文说64×64小波图，代码生成224×224；原CWT矩阵约128×1024，代码把128行补零到224、时间轴只保留前224列，丢弃大部分窗口时间信息。

ViT使用ImageNet预训练骨干，但新建的`512→128`头没有任何训练或权重加载，直接输出随机初始化投影；代码也未将标签用于ViT微调。因此“128维深度故障特征”及0.7755轮廓系数无法由附录这段代码得到。其后又对全部源域ViT特征拟合`StandardScaler`，若再随机拆分做源域测试，会产生预处理泄漏。附件代码只保存ViT向量与三项统计量，未实现正文列出的20余项手工特征、故障频带能量或真正的人工+深度融合。

### 问题二：源域四类故障分类

1. 将人工特征与ViT特征拼接，按四类标签组织数据。
2. 比较KNN、TCN、DenseNet与ResNet-CBAM，在6:4、7:3、8:2三种分层划分下计算准确率、宏平均精确率、召回率和F1。
3. 以7:3划分作为最佳设置，报告ResNet-CBAM准确率0.998，并以混淆矩阵和t-SNE解释类间分离。

关键证据：模型说明见PDF pp.16—18；参数与12组结果见pp.19—20；四个混淆矩阵见p.20；四模型t-SNE见pp.20—21；附录仅有ResNet-CBAM单模型代码见pp.40—42。

审计判断：正文称分层抽样，附录却使用无固定随机种子、无`generator`的`random_split`，不能保证类别比例，也无法复现实验。正文表6把KNN也写为训练200轮、批量32、Adam优化，这与KNN“无显式训练过程”的前文解释直接冲突。代码只跑ResNet-CBAM的单次7:3划分和20轮训练，正文却写100轮，并未实现KNN/TCN/DenseNet、三种划分或重复种子比较。代码设置`nclass=10`，正文任务只有4类；若训练标签是0—3，另6个输出只是无意义自由参数。

更关键的是样本口径不可能同时成立：正文筛选表称四类各362个，共1448个窗口（PDF p.8），按30%测试约435个；p.20的ResNet-CBAM混淆矩阵却每类约270个、总计1080个测试样本，对应的源数据规模远大于1448。p.19表中TCN 7:3准确率为0.972，但p.20混淆矩阵标题及文字又称TCN为0.990。附录分类代码读取`imgs/*.npy`和`labels.txt`，问题一代码只写出单个`feats_vit.npy`与`feats_stats.npy`，两问数据接口不相连；分类模型也只读取图像，没有使用人工特征或ViT 128维融合特征。99.8%不能由附录重建，也可能受到同一原始长记录的重叠窗口随机跨训练/测试所造成的严重泄漏。

### 问题三：无监督域适应与目标域16文件分类

1. 用源域均值/标准差标准化两域，并称用MIC筛选跨域共性特征。
2. 以ResNet-CBAM作特征提取/分类器，DANN通过梯度反转混淆域鉴别器，MMD缩小两域分布差异，总损失写为`Lcls+λ(Ldom+Lmmd)`。
3. 先源域预训练，再联合域适应，最后以KMeans、余弦距离和分类头概率生成目标域伪标签。
4. 用迁移前后t-SNE、MMD、目标类内聚性和跨域中心匹配度作无标签评估，并给A—P文件四类结果。

关键证据：框架与损失见PDF pp.22—24；目标特征表见pp.24—25；迁移前后t-SNE见p.26；16文件概率/标签与物理解释见pp.26—28；消融表见p.28；附录迁移代码见pp.43—45。

审计判断：附录实现不是正文所称ResNet-CBAM，而是两层普通CNN加一个巨大的全连接层；分类头为10类，KMeans固定8簇，均与4类任务冲突。最严重的实现错误是`loss_mmd`由`fs.detach().cpu().numpy()`与`ft.detach()`计算，已脱离PyTorch计算图，并且最终损失明确只有`loss_cls+0.1*loss_dom`，MMD没有加入反向传播。因此附录不是DANN+MMD联合优化。

域对抗也不完整：源域前向使用`lamb=0.0`时，域分类器接收`f*0.0`，域损失对源域特征提取器没有有效梯度；只有目标分支经过梯度反转。代码没有源域预训练/冻结—解冻交替、MIC筛选、源域统计量标准化、余弦类别匹配、文件级概率汇总或A—P标签输出。KMeans返回的0—7簇编号本身没有故障类别语义，也没有把簇映射到四个源域中心。故表9的四类标签不可能由所附程序直接生成。

迁移后源/目标点在t-SNE中混合只说明二维投影下域可分性下降，不能证明类条件对齐；图12只用域颜色/形状，没有显示故障类别，单一混合簇也可能是判别结构坍缩。MMD受核带宽和特征尺度强烈影响；无目标真实标签时，内聚性0.91与跨域匹配0.89依赖模型自己的伪标签和中心，属于内部一致性，不是目标准确率。正文对D.mat的解释还把“滚动体故障能量比”与表8实际列出的外圈/内圈能量比混淆。

### 问题四：事前、迁移过程与事后可解释性

1. 事前层面用模块化结构、DANN/MMD目标和余弦距离说明决策流程。
2. 迁移过程层面用t-SNE、MMD、类内聚性和跨域匹配度展示对齐。
3. 事后层面从四类各抽10个样本，以包络谱频点做SHAP局部解释，再展示四个单样本的4×4输出/归因图。
4. 汇总保真度、充分性、完备性、类内解释一致性、稀疏度、TCAV和Layer MMD，比较源域、迁移前目标域、迁移后目标域。

关键证据：事前结构与决策逻辑见PDF pp.30—31；迁移过程图见pp.31—32；SHAP局部/单样本图见pp.32—34；指标定义与表14见pp.34—35；附录解释代码见pp.45—46。

审计判断：正文先称2048点原始信号转为1024频点，随后单样本段又称1200个频点，图的横轴约为1200，口径不一致。附录只实现通用MMD、t-SNE、KernelSHAP和一个“屏蔽top-k后最大logit变化”的简化保真度；没有充分性、完备性、类内一致性、稀疏度、TCAV或Layer MMD逐层计算。因此表14绝大多数数字没有代码证据。解释程序另行加载`small_model.pth`，没有加载问题三的`DomainAdapNet`权重；`model_cpu`假定模型直接返回张量，而前面ResNet-CBAM和DomainAdapNet都返回元组，接口不兼容。将重要频点直接置零也可能构造出分布外样本，保真度需要掩蔽基线与敏感性分析。

SHAP图与包络谱幅值相似不能单独证明模型利用了BPFO/BPFI/BSF：需要把重要频点换算到Hz，报告转速与轴承几何产生的理论频率及容差，并和随机频带、非故障谐波做对照。论文虽在问题四分析中提到反事实和TCAV，但没有反事实样本生成、概念样本集、显著性检验或p值。故“目标域解释性接近源域水平”仅是作者报告，未由附录闭环。

## 数据切分、泄漏与评价口径审计

- 源域每个原始长信号先用50%重叠窗口切分，再随机拆窗口；若同一记录相邻窗口跨训练/测试，会共享一半原始采样点及相同工况背景，99.8%可能严重乐观。应先按原始文件/轴承/试验批次分组，再在组内滑窗。
- 数据筛选可能利用全体窗口的SNR百分位后再拆分，属于测试分布参与选择；ViT特征标准化也在全体源域上拟合。
- 论文没有说明ViT/ResNet预训练权重是否在目标相近数据上训练、是否冻结，也没有多随机种子、置信区间或按轴承实体留一验证。
- 目标域只有16个无标签文件；窗口级伪标签不能当作16个独立样本的验证。文件内大量相关窗口不会增加标签准确率的有效样本量。
- 无标签指标只能比较几何自洽。至少需要少量盲标目标域、不同工况已知标签验证集、或故障台架的跨设备外部数据才能估计目标准确率。
- 模型/特征选择、划分比例选择和最终性能似乎都使用同一数据集；7:3因表现最好而被选择后，没有第二层独立测试集，存在选择偏差。

## 可迁移规则与用户研究关联

- 轴承滑窗任务必须按原始文件、轴承实体或试验批次分组切分，不能先滑窗再随机拆分；这与时序研究中按完整序列/事件隔离的原则相同。
- 域适应要验证“类条件对齐”，不能只看两域整体混合。可检查按源域类中心的目标邻域、条件MMD、类间间隔和少量盲标目标样本。
- 任何损失都要审计是否真的在计算图中并进入总损失；写出MMD公式或打印MMD不等于模型用MMD训练。
- 伪标签的簇编号不是故障标签，必须有簇—类别映射、文件级聚合、置信度与拒识机制；目标无真值时不得报告准确率式结论。
- 可解释性应把`SHAP重要频点 → Hz → BPFO/BPFI/BSF/FTF及谐波/边带`闭环，并对随机频带、转速漂移和掩蔽基线做对照。
- 对用户关心的“预测与理解机制”边界，本篇可表述为`振动X → 学习表征Z → 故障标签Y`；高分类准确率或域混合不等于模型理解损伤机制，更不等于真实运营环境下的干预安全效应。
