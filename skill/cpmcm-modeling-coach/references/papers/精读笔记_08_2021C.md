## 总链条

**输入**：题给 HH 方程、AMPA/GABA 突触、基底神经节经典拓扑及交直流/DBS 波形。**机制**：以 Simulink 实现单 HH 神经元和化学突触，再把每个核团压缩为一个神经元，构造健康/PD 回路。**中间判断**：由波形峰数、振幅、频率、静息间隔和激活时间比较健康、PD 与不同刺激方案。**输出**：作者先选 STN 优于 GPi/SNr，再在扩展比较中选 GPe，并给出有限网格下的幅值、频率和占空比。**局限**：网络规模不满足题目给出的每核团 5–10 个神经元，突触电流符号与文字解释矛盾，优化实为少量手工情景比较，且没有工程文件、求解器配置或独立生理验证。

## 逐小问模型链

1. 题给 HH 方程 → 把稳态条件写成代数残差并称用信赖域法求平衡点 → 将 `V,m,h,n` 初值置为 `-65.0255,.0528,.5970,.3173` → 直流 10–50μA 和固定 20Hz、10μA 的正弦/方波响应及发放指标（p8–14）。
2. AMPA/GABA 动力学 → 两个“神经元—突触—神经元”例子 → 经典基底神经节连接 → 每个核团用一个 HH 子系统、突触用一个子系统 → 丘脑输入后观察运动皮层和内部电流（p15–23）。
3. 将 `SNc→dMSN` 和 `SNc→iMSN` 的最大电导置零模拟多巴胺缺失 → 单脉冲、9.2μA 阶跃和 10Hz 方波下比较健康/PD → 以 GPi/SNr 过兴奋及 STN–GPe 振荡解释运动迟缓和强直（p24–29）。
4. 在 STN 或 GPi/SNr 注入 100Hz、200μA、占空比12%的方波 → 以运动皮层波形接近健康态判定 STN 较好 → 手动扫描少量幅值并把丘脑输入增强10%作“鲁棒性”检查 → 推荐 STN 130–150μA（p30–34）。
5. 在 STN、GPi/SNr、GPe、Str 四处比较四组 DBS 波形和三组丘脑输入 → 统计每周期完整动作电位个数 → 作者最终推荐 GPe，给出 200μA、100Hz、占空比10%的方波（p35–41）。

- 作者报告单神经元直流刺激越强，频率由 82.7208Hz 增至 134.1202Hz、振幅由111.01mV降至82.16mV；交流正弦/方波均为簇发放（p12–13）。这些是同一 Simulink 模型的内部输出，不是实测数据。
- 作者报告基底神经节在不同直流幅值下运动皮层振幅近似恒定，并把这解释为反馈鲁棒性；没有外部重复、误差条或参数不确定性（p21）。
- STN 与 GPi/SNr 比较仅在同一组波形下进行，表6.3中 STN 的激活/静息时间更接近健康态（p31–32）；扩展靶点结论则来自有限情景表7.1–7.3（p39–41）。

## 验证、泄漏与一致性审计

- 本文不是监督学习，训练/测试泄漏不适用；对应风险是**校准与评价同源**：模型结构、参数、疗效指标和候选方案都在同一仿真器内选择，没有独立生理数据或外部模型验证。
- 题目允许每个核团简化为5–10个神经元，正文却明确“每个神经核团采用一个神经元子系统”（p20）。这消除了核团内异质性、同步性和随机性，不能用单节点结果支持群体动力学结论。
- HH 式把 `I_synapse` 以正号加入膜电位方程（p8），AMPA 又定义为 `g r(Vpost-E)`，静息时为负（p15）；正文却称该负电流会使突触后神经元去极化（p17）。在当前符号约定下解释方向相反，除非实现中另行取负号，但工程未提供。
- 突触参数段称“与 STN 连接的 β 取0.03，其他突触中 β 取0.03”，两类完全相同；连接表亦没有给出求解器、时间步长、初值扰动和全部 Simulink 连接细节（p21）。
- 平衡点求解把向量方程 `f(x)=0` 直接写成 `min f(x)`，未定义残差范数、容差或 MATLAB 调用；零输入恒定只说明该初值在同一实现中近似平衡，不是独立验证（p10–11）。
- 直流结论来自 10–50μA 的有限表，交流结论只用20Hz、10μA的两种波形，却被概括为一般规律；没有步长收敛、初值敏感性或分岔扫描（p12–14）。
- 问四的“鲁棒性”只把丘脑输入幅值提高10%，没有扰动神经元/突触参数、频率、噪声或初值；低功率结论也未计算电荷、能耗或等能量比较（p32–34）。问题五仅枚举4组DBS和3组丘脑输入，且8Hz丘脑输入下所有方案均不理想，仍不足以称全局最优（p35–41）。
- 引文对应存在明显疑点：p13用参考文献[1]支持交流频率13–30Hz，但文末[1]题名是突触知识误区；p15所称“比较五种化学突触模型”的[4]及模型来源[5]，与文末相应题名也不吻合（p13、p15、p42）。
