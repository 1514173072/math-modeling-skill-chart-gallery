## 总链条

**输入**：气象、土壤湿度/化学性质、植被与不同放牧制度。**机制**：水量平衡和随机植被动力学解释过程，灰色预测与树模型负责短期预测，AHP/熵权-TOPSIS负责退化评价，遗传/退火负责决策。**中间判断**：清洗、筛特征、预测，再把预测量送入评价和优化。**输出**：未来环境量、退化状态、放牧方式及载畜量。**局限**：时间序列被随机拆分且特征筛选先于拆分，报告指标很可能乐观；所谓组合模型缺少可执行定义。

## 逐小问模型链

1. 缺测气象/土壤数据 → 拉格朗日插值（p6）→ 水量平衡和贮水—湿度关系（p7–9）→ 用全年/禁牧/轮牧/轻牧/休牧的时间函数及高斯强度参数（p9–10）驱动含正态食量项的植被模型式(17)（p10–11）→ 文献算例与 G6 点对照（p11–12）。
2. 月度序列 → 3σ、割线补缺、删常量/高缺失特征（p13–14）→ Pearson、LASSO、Isomap、XGBoost 投票交集，留下蒸发、降水天数、能见度、最大持续风速、露点（p14–16）→ 同月份十年 GM(1,1) 外推气象（p16–18）→ RF/LightGBM 预测湿度（p18–25）。
3. 放牧和土壤化学量 → 碳守恒（p26–28）→ SIC/SOC 三次回归及 N–SOC 线性关系（p28–30）→ 未来化学指标表（p31）。
4. 环境与经济指标 → AHP 沙漠化（p31–34）和熵权-TOPSIS 板结化（p34–36）→ 多目标动态线性标定精英 GA（p37–38）→ 放牧制度。
5. 降雨场景 → 全氮与植被截流约束（p39–42）→ 模拟退火 → 最大载畜量。
6. 牧户强度 → 六指标预测（p42–46）→ 2023年9月状态表。

## 验证、泄漏与一致性审计

- 代码对时间序列使用普通 `train_test_split`，并以随机种子123（LGBM）和84（RF）打乱月序（p22、p51、p54）；这会把未来月份信息泄入训练。`GridSearchCV` 也不是滚动时间验证。
- 四类特征筛选看似在全量数据上完成后再切分，构成选择泄漏。120条样本上的随机CV不能支持真正未来泛化。
- 正文未给 RF+LightGBM 的融合公式、权重或元学习器；附录只有两个独立脚本，无法重建“组合”结果。
- 最终参数在代码中被注释，实际实例化默认 `LGBMRegressor()` 与 `RandomForestRegressor()`；正文调优模型和附录执行模型不一致。
- GM代码最终在全数据上拟合/评价，没有保留正文所述2012–2019训练、2020–2021验证的外推隔离。多维 X 直接 scatter 也可能不能按预期运行。
- 附录缺少特征筛选全流程、融合模型及问3–6代码，故论文内交叉验证不等于结果被本次复现。
