## 输入 -> 机制 -> 中间判断 -> 输出 -> 局限

机场逐分钟气象/能见度、连续视频帧和100张高速公路截图 -> 分位数回归、迁移CNN、暗通道先验与导向滤波、PSO-NGBM和ARMA -> 以拟合优度、随机帧测试精度和样本内MAPE选择模型 -> 能见度关系式、图像分级、100点能见度序列及散雾时间 -> 上限删失未建模、相邻帧随机切分、暗通道实现与公式冲突，且用约1小时的100点序列外推约24小时，散雾时刻证据很弱。

## 逐小问模型链

1. 问题一：两段24小时AMOS数据按整分钟对齐 -> 相关矩阵筛变量 -> 在0.05至0.95分位点比较系数与检验 -> 取RVR的0.5分位和MOR的0.6分位，给出气象要素关系式（PDF pp.10-25）。这是同一短时序上的描述性条件分位关联，不是气象因素的因果效应。
2. 问题二：机场视频按15秒截帧并匹配能见度 -> 22类标签 -> 预训练CNN冻结前层、微调100轮；另以颜色矩/GLCM特征训练BP网络对照（pp.26-34）。作者报告训练80.48%、测试79.63%，但以连续视频帧随机7:3切分，未按日期或雾事件隔离。
3. 问题三：100张高速公路截图 -> 暗通道、梯度导向滤波与全局大气光 -> 透射率 -> 消光系数和相机距离 -> 能见度序列（pp.35-44）。作者报告89.28-94.51 m、均值90.44 m，但附录实现没有真正执行正文的相机标定链，且透射率和大气光计算存在关键错误。
4. 问题四：对上述100点序列分别拟合PSO-NGBM(1,1)和ARMA(3,3) -> 按样本内MAPE选择ARMA -> 从第101点外推到第2158点，宣称2016-04-15 07:39:47达到200 m并视为雾散（pp.45-53）。这一长跨度外推没有预测区间、滚动验证或外部气象输入。

## 数据、切分与验证

- 问题一只使用2019-12-15/16和2020-03-12/13两段24小时分钟序列；RVR=3000、MOR=10000是仪器上限而非真实等值。作者在散点分析中直接剔除这些观测，却没有使用删失回归或敏感性分析（pp.11-12）。
- 回归比较全部是样本内拟合，没有按时间留出或跨天气过程验证。OLS表的Durbin-Watson仅0.145和0.083，提示强烈序列相关，但显著性与标准误仍按普通回归解释（pp.21-22）。
- RVR“非线性分位数模型”表4-8与此前分位数线性表4-5的系数、标准误和拟合量完全相同，最终方程也全为线性项；名称与实际规格不一致（pp.21、23-24）。
- 问题二共1858张匹配图像，随机7:3得到1298/558。图片来自同一连续视频，相邻帧极相似，随机帧切分会让同一雾事件和相邻时刻跨训练/测试；正文没有独立验证集、事件留出、类别分布或多随机种子（pp.27、31-33）。
- 训练过程中持续绘制“测试集”100轮的准确率和损失，并报告最高准确率；如果据此确定轮次或模型，该集合已成为验证集而非一次性测试集（pp.31-33）。
- 问题四仅有100个、间隔42秒的图像估计值，约覆盖69分钟，却外推2058步到约24小时以后；没有滚动起点评价、预测区间、结构突变检查或气象协变量（pp.43-53）。

## 关键结果与内部矛盾

- RVR(0.5)调整伪R²为0.6422；MOR(0.6)调整伪R²为0.6974（pp.23-25）。这些值是样本内拟合，不是预测性能。
- RVR方程中风速平方项系数为负，正文也称负关系，却紧接着用“风速增大有利于污染物扩散、能见度提高”解释，符号与机理叙述相冲突（p.24）。
- 问题二一处称“训练数据集1858张，测试数据集无标签558张”，但同时报告558张测试准确率；更合理的解释是1858张总样本再按7:3划分，正文集合命名不严谨（pp.27、31）。
- 高速图像采集时间在p.43为2016-04-14，p.44却写2016-04-16，日期内部矛盾；后续外推又回到4月14日至15日（pp.43-44、52-53）。
- ARMA阶数比较文字称AIC/SC“相对较大”更好，实际AIC应取小且ARMA(3,3)的SC并非候选最小；MA(1)系数p=0.7826仍保留。平稳性只是断言，未见ADF等检验；残差白噪声也只有结论性陈述（pp.50-51）。
- 作者报告PSO-NGBM和ARMA样本内MAPE为1.21%与0.63%；低样本内误差不能验证2058步外推。其所谓“最优参数取1.21”又与MAPE同值，参数语义不清（p.48）。

## 正文—附录—代码一致性

- 附录只提供描述/相关分析、EViews命令片段和暗通道MATLAB代码；没有CNN/迁移学习、BP、PSO-NGBM、ARMA的完整训练与评价代码，因此核心结果链不可执行（pp.65-70）。
- 正文透射率式要求先按大气光`A`归一化各颜色通道，附录却先以原始暗通道直接计算`Jt = 1 - 0.95*Jdark`，随后才估计`Ac`，`Ac`没有进入透射率估计（pp.37-38、66-67）。
- 估计大气光时，代码写成`Jdack(...)=0`而非`Jdark(...)=0`，最大像素未被删除；`Cnt=length(MaxPos(1))`始终只检查一个标量，不能按预期提前停止，最亮点集合可能被重复选取（pp.66-67）。
- 正文称以相机标定求距离L，附录没有内外参或标定数据，而直接在`belta=abs(total/(720*1280*30))`中硬编码30；89-94 m的绝对尺度依赖这个未经展示校准的常数（pp.40-43、67-68）。
- MATLAB代码固定图像为720×1280并循环1到100，无尺寸检查；仅声明“其余代码见附件”，当前PDF不足以重建完整链（pp.66-70）。

## 可重建程度与可复用思想

- 可重建：按业务时间对齐气象与能见度、采用透明分位数基线、事件级视频切分、暗通道与ARMA的标准版本。
- 不能重建原结果：缺CNN架构/预训练权重、标签分箱边界、冻结样本清单、相机标定参数、问题四代码与原始数据；已给MATLAB实现又与正文公式冲突。
- 可复用：把上限值视为右删失；按完整雾事件或日期切分视频；在短时序上用滚动起点比较持续性、ARIMA/状态空间/ESN，并输出预测区间和阈值到达时间分布。
- 不应复用：相邻帧随机拆分、用测试曲线选轮次、由样本内MAPE选择超长外推模型、用硬编码距离把图像亮度换算成物理能见度。
