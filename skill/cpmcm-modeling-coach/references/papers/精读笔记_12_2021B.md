## 输入 -> 机制 -> 中间判断 -> 输出 -> 局限

一次预报和实测的逐小时气象/污染物、逐日污染物 -> 主成分/聚类描述气象，FNN与时序模型订正单站预报，GCN与GRU聚合邻站 -> 按污染物比较误差并组合模型 -> 未来三天六污染物、AQI和首要污染物 -> 随机切分与测试集参与优化造成严重乐观偏差，空间图和业务时点契约不充分。

## 逐小问模型链

1. 问题一：按IAQI分段线性插值并取六污染物最大值得AQI；作者报告A站2020-08-25至28的AQI为60、46、109、138（PDF pp.6-7）。
2. 问题二：异常/缺失处理 -> 污染物分段指标、风向余弦“伪独热码”、Z-score -> 日内24小时SVD主成分、Spearman筛选、跨指标主成分 -> Two-Step聚类；NO2/颗粒物/O3分别分成6/9/5类（pp.8-21）。这是描述性关联分类，不是气象干预效应。
3. 问题三：随机森林重要度选择一次预报特征 -> FNN/RF/SVR/XGBoost比较；NO2/PM10/PM2.5以历史24小时LSTM-FC修正并用Lasso组合；O3先CEEMDAN降噪，再用IPSO选择40个Bootstrap-SVR并与LSTM组合；SO2、CO保留FNN（pp.22-35）。
4. 问题四：四站点组成图 -> 一次预报进入GCN，历史监测序列进入GRU-GCN-FC，再用Lasso组合；作者认为协同模型主要改善O3，对PM10/CO帮助不稳定（pp.36-41）。

## 数据处理、切分与验证

- 数据时间范围与每日7时信息边界在pp.8、22、28说明；LSTM输入预报日7:00前24小时，方向正确。但论文多处仅写9:1、8:2和普通5/10折交叉验证，没有说明按日期连续留出，不能排除未来日期进入训练（pp.8、22、24、32）。
- 缺失小时以前一小时填补，缺失日尝试由小时聚合，否则以前一日填补；标准化和随机森林筛选是否仅在训练折拟合未说明（p.22）。
- CEEMDAN很可能在切分前对完整O3序列处理；若如此，分解的双向信息会跨越测试边界。论文未给安全的逐折分解协议（pp.30-31、44-47）。
- 最严重问题：IPSO适应度直接以`testX/testY`的R²计算并反复选择SVR子集，正文也明确“将测试集输入”后寻优，因此测试集参与训练/选模（pp.32-34、48-50）。O3报告指标不能视为独立测试结果。
- 图模型只给0/1邻接矩阵概念，未清楚说明四站边的构造依据、距离阈值或权重；Pearson相关不等于传播边（pp.36-37）。

## 关键公式、参数与作者报告结果

- IAQI/AQI：式(1)-(2)，pp.6-7；风向变换式(3)与Z-score式(4)，pp.9-11。
- SVR使用RBF核，正文称C在[1,1000]、gamma/文中σ在[0.1,500]网格，5折；RF为10折，XGBoost为5折（pp.23-25）。
- LSTM-FC使用前一日8:00至当日7:00的24小时历史（p.28）。
- CEEMDAN加入100次白噪声；排列熵正文称嵌入维7、延迟2、阈值0.7；IPSO正文称40个SVR、20粒子、20迭代、阈值0.5、`c1=c2=0.2`（pp.30-34）。
- 作者摘要报告PM2.5 FNN偏差1.92、O3 FNN偏差17.14、CEEMDAN-IPSOSE-SVR偏差13.53；组合后PM2.5相对FNN/LSTM下降6.3%/9.1%；协同模型对NO2/O3/SO2/CO偏差下降17.4%/12.6%/3.6%/1.8%，PM2.5/PM10上升12.8%/1.0%（pp.2-3）。这些值没有独立复现。
- 最终三日单站和协同预测表在pp.35、41。

## 正文—附录—代码一致性

- CEEMDAN正文延迟为2，附录代码`delay=1`；正文噪声标准差与阈值公式同代码实现也不完全一致（pp.46-48）。
- IPSO正文`c1=c2=0.2`，代码为2；正文描述个体适应度，代码`calculate_fitness`只返回全粒子最佳标量并以同一标量更新所有个体；每轮固定随机种子还会重复随机数（pp.32-34、48-50）。
- Bootstrap函数在循环内部设置NumPy种子，但实际抽样使用Python `random.randrange`，随机性并未由该语句控制（p.48）。
- 正文称单层GCN足够，代码定义两层；正文称DropEdge缓解过拟合，代码两次调用的`level=0`实际不丢边（pp.37、50-51）。
- GRU-GCN代码给出网络主体，但附录明确“仅展示部分代码”，缺数据装载、邻接矩阵、训练循环、超参数表和Lasso组合实现（pp.51-53）。
