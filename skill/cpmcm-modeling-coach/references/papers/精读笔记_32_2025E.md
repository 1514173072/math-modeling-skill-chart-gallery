## 一句话定位

论文试图用“48→32 kHz重采样 → TVFEMD-WESK与GWO-MOMEDA二阶段降噪 → SMOTE → 36项时频熵特征 → MixHop融合 → RF/LSTM/CNN/ViT源域比较 → MMD+CORAL无监督迁移 → t-SNE、质心方差和注意力解释”形成完整链条；但附录没有GWO-MOMEDA、SMOTE和MixHop的闭环实现，问题二实际把2048点原始窗口送入另一套ViT，问题三代码又存在源标签丢失、未定义域分类器和未加载预训练权重等阻断错误，故论文的结果无法由PDF附录重建。

## 总体链条：输入 → 机制 → 中间判断 → 输出 → 局限

- 输入：161个源域台架振动文件和16个无标签目标域文件；目标域每个文件8秒、32 kHz、约90 km/h，对应轴承约600 rpm；源域含12/48 kHz、驱动端/风扇端和四种状态，PDF pp.4—5。
- 机制：筛选48 kHz驱动端信号并重采样到32 kHz；SMOTE把四类平衡到各28条；用2048点窗口、1024步长切片；TVFEMD-WESK选择IMF，GWO优化MOMEDA参数；提取16项时域、13项频域和7项熵域特征；MixHop聚合多阶邻居；比较RF、LSTM、CNN、ViT；最后在ViT表征上联合MMD和CORAL对齐源/目标域。
- 中间判断：故障频率、IMF加权包络谱峭度、GWO融合冲击指标、36维特征矩阵、多阶图邻域、源域Acc/AUC、MMD/CORAL损失、目标预测概率、t-SNE簇、质心距离和注意力热图。
- 输出：四类源域诊断模型、作者选出的ViT、16个目标文件的预测类别与置信度，以及迁移前后对齐和物理一致性解释。
- 局限：数据表示在“112条×40窗口×36特征”和“每行长序列→2048点窗口”之间冲突；SMOTE先于拆分；正文参数与代码参数不一致；核心预处理和MixHop代码缺失；迁移代码按原样不能正确携带标签或完成前向传播；无标签目标域没有真实准确率。

## 逐小问模型链

### 问题一：二阶段降噪、36项特征与MixHop融合

1. 从源域选择48 kHz驱动端加速度信号，降采样至32 kHz；用SMOTE把正常、滚动体、内圈和外圈四类各平衡到28条，再用2048点窗口、1024点步长切片，PDF pp.7—10。
2. 根据SKF6205几何参数和转速计算BPFO 107 Hz、BPFI 162 Hz、BSF 141 Hz，并以时域冲击及包络谱倍频解释三类故障，PDF pp.10—13。
3. 用TVFEMD分解信号，以WESK综合IMF与原信号相关性和包络谱峭度，选择高于均值的IMF重构；再以GWO搜索MOMEDA故障周期T和滤波器长度L，进行第二阶段降噪，PDF pp.13—18。
4. 从每个窗口提取16项时域、13项频域和7项熵域特征，共36项；把窗口视为图节点，用MixHop同时聚合0/1/2阶邻域信息，得到融合特征矩阵，PDF pp.18—23。

审计判断：正文方法链很丰富，但附录不能支撑它。附录MATLAB代码调用`tvf_emd`，却用普通峭度×能量权重代替正文“相关系数×包络谱峭度”的WESK，并硬编码选择`[1,5,8,9]`号IMF；正文示例则称选择IMF1—3且依据高于均值，PDF pp.44—46。附录Python又调用普通`PyEMD.EMD`而非TVFEMD，并简单求和前5个IMF（pp.47—50）。全文没有GWO、MOMEDA目标函数/滤波实现，也没有SMOTE或MixHop训练代码，因此图4.8、图4.9及所谓增益无法从附录重建。

数据口径也不统一。正文先称重采样到32 kHz，附录特征函数却以`fs=48000`调用（PDF p.50）；附录窗口循环从原始行每1024点取2048点，与正文相符，但后续又对窗口做一次EMD。熵特征中`fuzzy_entropy = sampen`，即直接用样本熵冒充模糊熵；包络熵对`density=True`直方图密度直接做`-Σp log p`，没有先归一化为概率；`targe_df`在所示片段中也未定义。故36项特征虽可据表4-8独立实现，附录产物并非无歧义的36维数据表。

MixHop还缺少最核心的图定义：正文没有说明节点如何连边、邻接矩阵来自时间相邻、特征近邻还是同一文件，也没有训练目标和输出维度。没有邻接构造，`A^0/A^1/A^2`的“多阶邻居”只是概念，无法复现融合矩阵或解释类别纹理。

### 问题二：RF/LSTM/CNN/ViT源域诊断

1. 正文称输入为问题一的MixHop融合特征，把数据8:2随机拆为训练/测试，比较RF、LSTM、CNN和ViT，PDF pp.24—29。
2. 作者报告ViT 95.7%、LSTM 87.0%、CNN 82.6%、RF 87.0%，并给出混淆矩阵、损失曲线、AUC和10次随机实验箱线图，PDF pp.29—31。
3. 以ViT作为后续迁移骨干，正文参数为Patch 16、嵌入128、12层、12头、MLP比例4.0和Dropout 0.1，PDF pp.27—28。

审计判断：正文与代码处理的是不同数据对象。正文说训练集含112条样本、每条40个窗口、每窗36项特征（PDF p.28），即单条特征矩阵为40×36；附录问题二却从`data4_resampled_32khz_balanced.csv`读取每行长序列，先逐行标准化，再按行8:2拆分，然后生成2048点原始信号窗口送入1D ViT（pp.51—56）。40×36只有1440个元素，甚至不足以形成一个2048点窗口。代码完全没有读取MixHop输出或36维特征矩阵，故不能把95.7%归因于正文所述“36特征+MixHop+ViT”。

ViT参数也不一致：附录使用Patch 64、嵌入256、6层、8头、MLP 512、30轮和AdamW 1e-4（PDF pp.52—56），与正文表5-1的Patch 16、嵌入128、12层、12头和100轮等不符。RF/LSTM/CNN实现、ROC计算和10次稳定性实验代码均未提供；图5.9文字还把箱体“宽度”解释成波动大小，而标准箱线图的离散程度应看纵向箱高和须长。

附录先加载文件名含`balanced`的数据再拆分，和正文“先SMOTE平衡、再8:2拆分”一致。若该平衡文件由全体原始样本统一SMOTE生成，则测试样本的合成过程已经使用测试邻域信息；正确顺序应先按原始文件/工况拆分，只在训练集内拟合SMOTE。当前没有SMOTE代码、原始文件ID或分组信息，无法排除合成样本近邻跨集合。

### 问题三：ViT上的MMD+CORAL无监督领域自适应

1. KDE显示源/目标36项特征分布不同；作者用RBF核MMD匹配RKHS均值、用CORAL匹配协方差，并把二者相加作为高阶与二阶矩联合损失，PDF pp.31—34。
2. 源/目标网络权值共享，分类损失只用源域标签；正文称以任务二最佳ViT权重初始化，每批输入等量源/目标数据，使用SGD、学习率0.01、权重衰减5e-4和动态正则系数，PDF pp.34—36。
3. 作者给出分类、CORAL、MMD损失曲线，并预测16个目标文件，报告四类分布及文件级置信度，PDF pp.36—38。

审计判断：附录问题三按原样存在多个运行阻断。`set_seed(42)`在调用前未定义；`DomainDataset._create_windows()`从不向`window_labels`追加源标签，因此`self.source_labels`为空，合并后的`class_labels`长度与全部窗口不一致，源域训练标签会错误或越界，PDF pp.57—58。`DomainAdaptationViT.forward()`又调用`self.domain_classifier(features)`，但构造函数从未定义`domain_classifier`（pp.58—60），会直接触发属性错误。论文没有运行作者代码，本笔记因此只能判定静态代码不闭合，不能把正文损失曲线视为由所附脚本可重复生成。

即便修复阻断，训练协议仍与正文不同：代码新建随机初始化模型，从未加载问题二的`best_vit_model.pth`；使用AdamW 1e-4而非SGD 0.01；MMD和CORAL权重固定各0.1，没有式(38)的动态系数；源/目标窗口合并后整体shuffle，并不保证每批等量；最佳模型只按源域训练准确率保存，没有独立源域验证，PDF pp.61—65。MMD实现还固定RBF宽度为1、忽略函数参数并用双重循环构造核矩阵，正文所谓多核/高阶策略没有实证拆解。

代码最多为每个源/目标序列取10个窗口，`evaluate_model()`输出的是目标窗口级标签，再以0—159式`sample_id`写CSV（PDF pp.57、62—65）。没有把窗口聚合回A—P 16个文件，也没有Softmax置信度计算。因而表6-2的文件级类别和置信度不能由附录输出链生成。

### 问题四：迁移过程与事后可解释性

1. 作者用迁移前/后的t-SNE展示目标点由散乱到与源域类别对齐，PDF pp.39—40。
2. 在t-SNE二维坐标中计算源/目标质心距离0.31和方差覆盖，并以到源域中心的距离分布说明残余偏差，PDF p.40。
3. 用最后一层注意力热图说明迁移后关注从局部尖峰扩展到更广时频区域，并对应BPFI/BPFO/BSF/FTF、倍频和侧频带，PDF pp.41—42。

审计判断：附录问题四加载的是标准化后的原始源/目标特征，目标赋虚拟标签-1；其片段没有加载迁移模型或任务二模型，也没有抽取“迁移前/后深层特征”。`create_tsne_visualization`、`create_detailed_analysis_plots`和`args`均未给出定义，PDF pp.66—69。现有`analyze_domain_separation`还在t-SNE投影上按最近源类质心重新给目标分类，这不是问题三ViT输出。t-SNE会扭曲全局距离且受随机种子、困惑度和尺度影响，坐标中的0.31没有跨运行可比性，不能证明原特征空间完成了二阶/高阶对齐。

注意力图没有对应提取代码。问题二自定义注意力只在内部计算`attn`而不返回，问题三使用`TransformerEncoderLayer`也未挂接权重导出；附录末尾没有图7.4生成流程。正文还声称模型在“阶次归一化后”关注相同故障阶次，却没有阶次跟踪或转速归一化步骤；四分类也不含保持架故障，却反复解释FTF。故注意力—物理机理关系是事后叙述，尚未被频带遮挡、注意力干预或类别真值验证。

## 数据单位、切分与泄漏审计

- 独立单位应是原始振动文件/工况，而不是2048点窗口。相邻窗口重叠50%，必须让同一文件的全部窗口留在同一集合。
- 正文从平衡后的112条样本随机8:2拆分；若SMOTE在拆分前全局拟合，会把测试邻域信息带入训练。必须先分原始文件，再仅在训练折内SMOTE。
- 问题二代码按行拆分后再切窗，方向上比窗口后随机拆分更合理，但缺少`origin_file`和工况分组，且输入对象不是正文的36维MixHop特征。
- 每行序列在拆分前用自身全长均值/标准差归一化。这不跨行共享统计量，但属于“整文件已知”的转导式预处理；若任务要求在线早期诊断，应只用已到达片段或训练参数。
- 问题三把所有源/目标窗口合并随机批处理，没有源域验证集、目标盲测封存或文件级聚合。最佳模型按源域训练准确率选取，不能评价跨域泛化。

## 可迁移规则与用户研究关联

- 这篇论文适合作为“模型链越长，接口审计越重要”的反例：`信号X → 降噪Z1 → 特征Z2 → 图融合Z3 → 分类Y`，任何中间产物形状、文件名或参数不一致，后续高精度都无法归因。
- 对用户的时间序列/RC路线，可用ESN/RC替代LSTM或ViT做2048点窗口基线，但应以原始文件为组做外推，并报告新转速/负载下的性能；RC预测好不等于识别故障因果机制。
- 对非线性动力学，可把熵、包络谱和RC状态作为互补表征，但模糊熵、样本熵、EMD能量熵必须按各自定义实现，不能用同一数值换名。
- 对无监督迁移，优先做“源域文件级基线 → 仅训练集SMOTE → 固定预处理 → 目标域盲预测 → 分布/物理稳定性证据”。MMD、CORAL、t-SNE和置信度都是间接证据，不是目标准确率。
- 对可解释性，注意力热图只能说明权重分布。要声称关注BPFO/BPFI/BSF，应把频率轴、转速归一化、遮挡实验和预测变化绑定起来，并避免解释数据中不存在的FTF类别。
