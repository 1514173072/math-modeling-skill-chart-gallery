## 输入 -> 机制 -> 中间判断 -> 输出 -> 局限

三个高度的ZH/ZDR/KDP雷达序列和降水格点 -> 强对流事件过滤、三分支U-Net、损失消融、Z-R拟合和门控融合 -> 用CSI及连续/图像指标比较输入与损失方案 -> 未来10帧ZH、降水量及变量融合方案 -> 事件切分不可复核、训练代码与正文损失不一致，测试过程还参与逐epoch观察。

## 逐小问模型链

1. 问题一：以35 dBZ、256 km²过滤非强对流事件；前三变量各用10帧进入独立四层编码器，在最高语义层拼接并经SE-Block重分配，公共解码器输出未来10帧ZH（PDF pp.11-23）。
2. 问题二：比较强/弱区域固定加权、自适应面积加权、SSIM和对抗损失八种组合；正文称Case3固定加权+SSIM在前30分钟CSI更稳定，表4则给Case1-4的连续指标（pp.23-30）。
3. 问题三：用`R=a*ZH^b*ZDR^c`非线性最小二乘和双分支U-Net估计降水格点；作者结论为卷积网络指标更好（pp.30-35）。
4. 问题四：以重复ZH、双变量和三变量输入做消融，再将三对Bi-GFF与SE-Block结合进行特征融合（pp.35-41）。输入替换实验只支持模型内增量贡献，不证明雷达变量的物理因果贡献。

## 数据、切分和验证

- 原始数据为2014-2019年258个降水事件、三个高度、256×256格点、约6-7分钟间隔（pp.9-12）。过滤后作者称1 km层剩8910张图，前8000训练、后910测试，不打乱。
- 模型实际样本是20帧窗口而非独立“图片”。附录按每个事件每20帧构造不重叠的10帧输入+10帧标签，再按`os.listdir`返回顺序拼接（pp.52-53）。由于目录和文件未排序，“前800/后91个窗口”的具体事件边界不可稳定复现；也没有明确验证集。
- 正文称采用提前停止监控验证集（p.26），附录却固定训练20 epoch，并在每个epoch后对800-890测试窗口评价和保存模型（pp.55-59）。若据这些测试曲线选择epoch或方案，测试集成为选模集。
- 只展示少数图像样例和整体平均指标；没有按完整事件留出、逐事件方差、季节外推或多随机种子稳定性。

## 关键设置与作者结果

- U-Net四层通道64/128/256/512；Adam `lr=0.001, betas=(0.9,0.99)`；batch=1；SE缩减率16（p.19）。
- 强对流阈值35 dBZ；输入/输出各10帧；问题二正文权重`w1=6,w2=1`，SSIM组合权重1，对抗0.01（pp.20、24-27）。
- 摘要报告问题一第6分钟CSI=0.62、MAE=0.70、RMSE=2.83、SSIM=0.95、PCC=0.34；问题二示例含60分钟CSI=0.52；问题四Bi-GFF为MAE=0.51、RMSE=2.78、SSIM=0.97、PCC=0.29（pp.1-2）。均未复现。
- 表4：Case1/2/3/4的MAE分别0.89/2.68/0.86/0.61，RMSE 4.35/3.98/4.45/3.24（p.30）；正文一处误写“MAE和PCC越低、RMSE和SSIM越高越好”，RMSE方向错误（p.27）。
- Z-R表5中归一化模型NE=1.721、RMSE=0.0717、CC=0.6829，而卷积模型NE=0.89、RMSE=2.96、CC=0.73（p.35）。不同归一化尺度下RMSE不可直接横比，且归一化Z-R的NE反而更差，正文“归一化必需/更好”的概括不由全部指标一致支持。

## 正文—附录—代码一致性

- 正文反复称L1/MAE重构损失，附录却定义`l1 = nn.MSELoss(reduction='sum')`（pp.15、24-26、53）。
- 附录`mask=(gt<35)`，`loss_hole`计算强对流区误差但未进入最终损失；最终式为弱区误差/弱区面积加上`6*强区面积/(强区面积+1)`常数，强区项对网络几乎无梯度，仅SSIM间接作用（pp.55-56）。这与“强对流区固定加权”核心主张冲突。
- 正文说八方案消融，附录只是一个通过注释切换的脚本，没有训练日志、独立配置或模型权重；当前对抗损失代码完全被注释（pp.49、55-56）。
- 正文编码块含BatchNorm，附录所有BatchNorm均被注释；正文称Case3等设置，代码实际同时启用面积相关项和SSIM权重200，与正文`lambda=1`不符（pp.15-16、19、55-56）。
- 附录训练/测试硬编码800与91个窗口、依赖未排序文件系统；没有随机种子、DataLoader、验证集、归一化、问题三拟合代码或完整多高度实验入口。
- 代码的数据清洗直接递归删除未达阈值的源事件目录，是不可取的破坏式预处理；这也增加无法复核样本清单的风险（pp.51-52）。

## 可重建程度与可复用思想

- U-Net/SE/Bi-GFF架构主体可据附录重写，CSI与部分评价函数也可重建。
- 原结果不可可靠重建：缺数据附件、冻结事件清单、确定排序、验证协议、问题三完整代码和方案配置；核心损失代码与正文冲突。
- 可复用：按事件留出后比较持续性/光流/ConvLSTM等基线；按提前量同时报告CSI/POD/FAR、连续误差与尾部强度；输入消融与门控融合要在统一协议下多种子重复。
- 不应复用：按文件系统顺序切分、每epoch查看测试集、把单张图像观感当“模糊效应”验证、破坏性删除原始数据。
