## 输入 → 机制 → 中间判断 → 输出 → 局限

- 输入：机场AMOS气象/跑道视程，机场长视频及同步能见度，高速公路100帧截图、车道线几何。

- 中间判断：能见度3000m的饱和区间；6档视频类别；透射率、消光系数和道路深度；ARIMA阶数；注意力时间权重；MOR何时达到150m。

## 逐问模型链与关键证据

### 问题一：气象因素与能见度

1. 检查时间戳缺失，对相邻时刻线性均值填补；已有时间戳的指标无缺失；箱线图离群点因连续变化而保留，PDF pp.4—6。
2. 两个日期共11520个RVR/风速样本；温度、湿度、气压为每分钟2880点，因此先对分钟内4个能见度取均值，p.6。
3. 对气压、温度、相对湿度、风速分别观察能见度饱和在3000m的区间；非饱和段用三角/指数等函数变换，再以多项式特征形式求联合线性回归解析解，pp.6—10。

审计：同一两天的高频记录具有强自相关，普通回归标准误会把分钟点视为独立；变量关系混合了昼夜趋势、共同天气过程和RVR上限截断，系数不应解释为气象因果效应。论文没有提供跨日期验证误差或关系式外推区间。

### 问题二：ResNet-LSTM视频估计

1. 长视频切为一分钟短视频；按能见度分为`<50, 50—100, 100—200, 200—500, 500—3000, >3000`六类，PDF pp.10—13。
2. 每分钟按约25 fps形成1500帧、每帧352×288×3；ResNet34逐帧输出6维，三层LSTM输出12维状态，再全连接为6类，pp.13—14。
3. 数据按6:2:2训练/验证/测试；ImageNet预训练ResNet34，初始学习率0.01，plateau减半，batch 64，100 epoch，Adam，pp.14—16。
4. 测试集138个视频，以类别错判率评价，p.17。

作者报告、未复现：错判率17.23%，错误集中在低能见度，p.17。没有混淆矩阵、每类样本量、宏F1或连续米制误差，无法判断相邻档误判与严重误判。

可行性审计：正文宣称单批输入`64×1500×352×288×3`并逐帧ResNet，显存/计算量极高；未说明实际是否抽帧、分块或缓存特征。附录pp.38—44只给接近PyTorch官方实现的ResNet定义，没有LSTM融合、视频数据集、训练/验证、损失和138视频评价入口，正文架构无法据附录重建。

### 问题三：暗通道—道路几何反演

1. 暗通道在局部窗口和RGB通道取最小，推导粗透射率；由`t(x)=exp[-sigma d(x)]`与Koschmieder得到`MOR=-2.998 d(x)/ln t(x)`，PDF pp.19—21。
2. 用引导滤波细化透射率，局部线性模型与正则化目标见p.21。
3. 依据车道线长6m、间隔9m和摄像机几何推导像素纵坐标到道路深度的有理函数；假设安装高10m，pp.21—24。
4. 对06:30:26—07:39:11每30—40秒取一帧，共100帧；取图像下半部`360×1280`透射率均值，结合道路深度得能见度，pp.24—26。

作者报告、未复现：首帧30.19m，07:38:30为67.64m，07:39:11回落至59.17m，p.25。等级表p.25把2级写为`100<L<500`，与1级`200<L<500`重叠，应核对标准原文，不能直接复用。

审计：把整幅下半图透射率平均后再配一个道路深度，会丢失像素对应的空间深度关系；暗通道不满足于天空、亮目标、车灯/反光区域；固定大气光、固定相机和无车辆假设很强。没有能见度仪同期真值，因此该曲线只是模型估计，不能称测量精度已验证。

### 问题四：ARIMA、Seq2Seq-Attention与所谓融合

1. 将100点序列分解为趋势、周期与残差；趋势二阶差分，按AIC/BIC选ARIMA(2,2,6)，残差以Ljung-Box检验，PDF pp.26—32。
2. 帧间平均步长由首尾时间计算为41.25s；ARIMA预测到MOR 150m的步号172.4，作者换算为再过7111.5s、09:37:43，p.33。
3. 因100点不足，作者在相邻帧间随机采用线性或拉格朗日插值，每3—5秒插值；Seq2Seq编码10点、解码2点并递归预测，注意公式与参数见pp.33—34。
4. 插值后按时间70%/20%/10%划分、训练500轮；作者报告验证RMSE 6.16、测试最小RMSE 10.32，p.34，未复现。Seq2Seq达到150m的作者时间为6637.1s、09:29:48，p.35。
5. “融合”没有学习权重或组合预测，只把两模型阈值到达时间取为`09:29:48—09:37:43`区间，pp.35—36。

## 数据单位、时间切分与泄漏审计

- 视频基本独立单位应是完整雾事件/日期，而不是一分钟片段。论文只写6:2:2；若连续相邻分钟随机拆分，背景、镜头和雾状态高度相似，17.23%错判率会偏乐观。
- 视频标签若由同步仪器值映射，需要明确一分钟内聚合、时间对齐和边界档样本；预处理及增强必须只在训练事件拟合。
- 问题四的70/20/10顺序切分方向合理，但必须先切原始时间段，再只用训练段内部插值。若先在全100点间插值再切，边界附近插值同时使用未来点。
- ARIMA在全100点分解、定阶并直接外推，没有独立后验真值；Seq2Seq的“测试最小RMSE”若从500 epoch中选择测试最小值，测试集参与选模。
- 递归预测越过远超观测长度的时域后，误差会累积；仅给单条阈值交点，未给预测区间或对插值随机性的敏感性。

## 可复用思想与适用条件

- 可复用：视频任务分成“逐帧空间编码 → 跨帧时序编码”，但应先抽帧或缓存帧特征，并按事件划分。
- 可复用：物理反演提供可解释基线，深度模型提供数据驱动补充；二者应在同一同期真值上比较或校准。
- 可复用：预测散雾阈值时直接报告“首次越过阈值时间”和不确定区间，而不是只报告未来序列RMSE。
- 条件：相机内外参、车道几何和大气光要逐场景校准；暗通道适用区域需掩膜；时间增强不能跨划分边界；模型融合需由验证数据学习或给出清楚的情景包络语义。
