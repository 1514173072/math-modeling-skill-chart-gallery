# ODE、变分法与最优控制

## 方法选择

- 已知状态随时间的演化率、守恒或相互作用，目标是模拟/估参：以ODE或状态空间模型为主。
- 目标是选择一条曲线、形状或函数，使泛函极值，且约束可由边界和等式清楚表达：考虑变分法。
- 存在随时间变化的控制、动力学约束、控制界、状态/路径约束或终端目标：考虑最优控制。

三者不是互斥标签。ODE可以嵌入参数估计和优化；经典Euler-Lagrange直接推导对复杂不等式约束不方便，但变分不等式、乘子/KKT、障碍问题和直接离散法仍可处理相应扩展。

## 先做可行性守门

在推导“最优”之前检查：单位和符号；初值与终端条件是否兼容；控制界和给定时间下的可达集；状态、路径和终端约束是否冲突；守恒量或积分界是否已证明不可达。不可行是有效结论，应给出界或证书，不能继续制造一条候选轨迹。

## ODE建模

按“状态/反馈结构图 -> 守恒或物理规律 -> 方程 -> 初边值条件 -> 参数 -> 数值求解”展开。二阶系统改写为一阶状态系统后再调用求解器。

分段动力学应说明切换条件、切换时刻是否自由，以及状态连续还是经过重置映射。无冲击普通ODE通常状态连续；碰撞、脉冲或混杂系统可能发生跳变。时间尺度相差大时检查刚性并选用适合的隐式求解器。

最低验证包括单位/量纲、已知极限、平衡点或守恒量、步长和容差收敛、初值与参数敏感性、动力学和边界残差。求解器返回成功只证明一次数值运行完成。

## 变分法

明确泛函、允许函数空间、边界条件和正则性，再推导Euler-Lagrange方程。多函数、高阶导数、自由端点和终点受曲线约束时使用对应的自然边界或横截条件；必须结合端点几何解释扰动方向。

求出通解后，仍需用边界、数据或物理条件识别积分常数，并检查候选驻值曲线是极小、极大还是鞍点。必要条件不等于全局最优。

## 最优控制

先写完整问题契约：状态、控制、参数、动力学、初值、终端状态/时间是否固定、控制集、路径/状态约束、积分成本和终端成本。

固定Hamiltonian的符号与极小/极大约定，然后逐项核对状态方程、协态方程、控制条件和横截条件。PMP通常给候选极值轨线的必要条件；只有凸性/凹性充分条件、验证定理、全局下界或其他证书成立时，才称全局最优。

先判断Hamiltonian关于控制的结构：

- 控制仿射且无奇异弧时，边界取值和Bang-Bang切换较常见；检查切换函数、奇异弧、有限切换条件和颤振。
- Hamiltonian关于控制严格凸且控制集闭凸时，点态控制极值条件通常唯一；只有在控制仿射、二次控制代价等使无约束极小点可显式求出，并且控制集为闭凸集时，才可写成欧氏投影/饱和律。仅有运行代价严格凸或控制有界并不足以推出投影形式。不要把“饱和—光滑—饱和”统称为纯Bang-Bang。
- 状态、路径或混合约束并非Hamiltonian“天然自动处理”，还需乘子、互补条件、边界弧或直接法。

PMP求出的时间控制通常是开环。只有明确得到 `u=pi(x,t)` 或通过HJB、反馈综合、MPC、相平面切换律等构造，才称反馈/闭环策略。

## 间接法与直接法

- 低维、结构清楚、需要解析控制形态：用PMP/打靶等间接法，并验证边界与切换条件。
- 高维、复杂路径约束、多阶段或间接法不稳定：优先直接配点、多重打靶或转录为非线性规划。
- 可用时，以独立离散化、动态规划或另一求解器交叉核对目标值和轨迹。

## 输出与终检

至少输出状态、控制和关键派生状态；适用时标出控制界、活跃约束、切换时刻、相平面或切换函数。报告动力学残差、终端残差、最大约束违反、网格/容差和目标值收敛；使用PMP/间接法时，再按所选极小或极大约定检查Hamiltonian极值条件残差及切换稳定性，不要无条件统一写成“Hamiltonian最小化”。
