# 复现与可信度审计

## 状态

- `indexed`：仅确认路径、年份和题号。
- `screened`：已读封面、摘要、目录和方法概览。
- `full_read`：完整读取正文、结果、参考文献和附录，并留有页码证据。
- `model_reconstructable`：公式、参数和流程足以重建模型逻辑。
- `code_runnable`：代码、环境和依赖齐备且成功运行。
- `numeric_reproduced`：关键表图或指标在明确容差内重现。
- `scientifically_validated`：数据划分、识别假设、稳健性和外部证据支持主结论。

状态是证据层级，不是自动流水线。程序运行不能证明科学结果成立。

## 逐篇检查

1. 核对题号、题面版本、页数和源路径。
2. 为每个小问登记模型、输入、输出、关键公式和结果页码。
3. 检查正文、附录代码、参数和结果是否一致。
4. 检查数据切分、泄漏、样本量、指标、基线和不确定性。
5. 列出缺失的数据、代码、随机种子、软件版本或外部服务。
6. 只按现有证据赋予状态，并写明阻止升级的条件。

## 四份先行契约

复现论文或开始新题数据建模前，先写四份短契约。缺一项就不能根据高分指标判断模型可靠：

1. **样本单位契约**：一行究竟是独立个体、同一患者的一次随访、同一字符的一次刺激、同一视频的一帧、同一天的一个站点，还是同一天气事件的滑窗。切分必须隔离真正的独立单位。
2. **数据语义与观察过程契约**：标签属于记录、对象还是事件；事件是准确发生、首次被观察到还是两次观测之间；是否有左/区间/右删失、反复阈值穿越或由状态决定的观测安排；记录级动态变量与个体固定属性不能混用。
3. **信息时点契约**：对每列注明在预测/决策时是否已经可见。未来实测气象、全期均值、双向插值、结局后变量和由完整序列分解出的特征均可能越过边界。
4. **评价契约**：训练集拟合参数与预处理，验证集选模型、阈值、组数和切点，测试集只评价一次。若逐轮查看`test loss`、按测试集选超参数或报告测试集最高值，该集合已成为验证集。

新题中把四份契约作为冻结工件进入最终自审；确需修改时记录原因、时间和受影响结果，不能为改善测试表现静默改写。

## 自评模式

审计自己的解题方案时，使用 `assets/self-audit-template.md`，每项给状态、证据指针、重算/断言和阻止通过条件。作者自检不等于第三方复核。

状态映射应基于证据而不是完成感：代码运行成功可记为运行层通过；主表/主图从冻结输入按容差重现后才是数值一致；数据切分、识别假设、稳健性和外部证据仍可能只部分通过。没有外部基准时，“数值复现”可标不适用，但必须说明本项目内部结果重算是否一致。

发现负结果、弱识别或图文冲突时，不用总分抵消。把相应项标为部分通过/不通过，写明哪些结论仍成立、哪些必须降级，以及需要什么证据才能升级。

作者环境中用同一实现重跑并与结果文件一致，只能证明内部数值一致。核心统计量需要不同实现、标准库或解析恒等式复核后，才能把对应行标为“独立复算”；事件定义、评价协议和识别假设仍需另行判断科学有效性。

## 常见泄漏与正确隔离单位

| 数据形态 | 常见错误 | 最低合格切分 |
|---|---|---|
| 单变量/多变量时间序列 | 随机划分重叠窗口、全序列标准化、先分解后切分 | 按预测起点连续或滚动切分；预处理只在训练窗拟合 |
| 多站点时序 | 同一日期的不同站点跨折、站点与日期都未留出 | 视目标采用留未来日期、留站点或双重阻断验证 |
| EEG/轴承切片 | 同一被试、字符、工况或原始信号的切片跨折 | 以被试/字符/原始记录/工况分组 |
| 视频与雷达序列 | 相邻帧或半重叠天气窗口随机分割 | 以完整视频、完整天气事件或日期分组 |
| 临床纵向数据 | 同一患者多时点跨折、用结局后信息聚类或筛特征 | 以患者分组；特征截断在预测时点；结局完全封存 |
| 空间场 | 相邻网格随机留点导致空间插值优势 | 留区域、留站点或距离缓冲的空间交叉验证 |

只要插补、缩放、降维、特征筛选、信号分解、SMOTE、伪标签或超参数搜索在全数据上先执行，即使随后正确切分，评价仍可能泄漏。

## 因果语言分层

- **预测**：`X`提高了对`Y`的样本外预测；不能写成`X`导致`Y`。
- **观测方向**：传递熵、CCM/RCM或有向图分数提示`X -> Y`的动态方向；仍不等于`do(X)`效应。
- **模型情景**：删除特征、替换输入、模型内断边或设置极端天气状态，得到的是模型依赖的情景/消融结果。
- **干预效应**：需要明确处理、结果、时间零点、混杂控制、识别假设、估计量和推断。
- **反事实**：需要个体或单位层结构模型及可识别的跨世界假设；普通预测轨迹、LSTM外推或输入替换不够。

医学治疗频数、特征重要性、PCA载荷、聚类差异和相关网络均不能单独支持疗效或机制因果结论。

## 缺少数据时的复现请求清单

按优先级请求最小闭环，而不是笼统索要“全部附件”：

1. 原始输入、字段字典、单位、时间/空间坐标与缺失值编码；
2. 样本ID、分组ID、预测时点、标签生成规则和冻结的训练/验证/测试索引；
3. 从原始文件到模型矩阵的脚本，以及仅在训练折拟合的预处理参数；
4. 模型入口、依赖版本、随机种子、超参数搜索空间和模型选择规则；
5. 生成主表/主图的评价脚本、容差、基线结果和中间产物校验值；
6. 若涉及优化，再请求全部约束、边界、初始状态、求解器设置和可行性检查；若涉及因果，再请求时间零点、处理分配、混杂变量和敏感性分析定义。
