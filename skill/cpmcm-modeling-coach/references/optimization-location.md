# 选址、容量与定价的实现模式

适用于0-1选址、容量分配、档位满意度、定价/补贴和灵敏度类赛题。先执行 `optimization-integrity.md` 的通用完整性检查；本文件只补充领域实现选项。统计类语义见 `survival-longitudinal.md` 与 `validation-integrity.md`。

## 1. 硬约束与供需缺口（最高优先级）

题面给定的数值约束（容量、预算、半径、比例上限）是问题定义的一部分。**求解结果不理想不构成放宽理由**——可行方案少、覆盖率低、大量未满足需求，本身就是题目数据设计的可能结果，如实报告即是正确答案。

- 模型必须显式包含未满足需求变量（或未服务量口径），覆盖率与满足率分层报告。
- 允许超容量运行、截断、惩罚外推等放宽口径只能作为登记的**对照口径**；严格约束版本是主口径。把对照口径改为主口径需要用户明示授权。
- 若严格容量下覆盖率或满足率较低，主结果就是对应缺口与上界，而不是改口径追求更好看的数值。

**分层目标模板**（容量紧张时的标准形式）：
1. 第一序：最大化实际服务人口（或总有效服务量，受容量硬约束）；
2. 第二序：在第一序最优解集内最大化需求满足率（或最小化未满足缺口）；
3. 第三序：最大化加权满意度。
字典序逐层求解，每层最优值与层内可行域规模都报告。

## 2. 服务分配与选站规则

题面"老人只选满意度最高的站"的落地口径（按忠实度排序）：

1. **完整满意度分配+拥挤度迭代**（最忠实）：分配 → 利用率 → S₂ → 重分配，迭代到稳定。可能不收敛（振荡）——此时进入 2 或 3。
2. **Logit 离散选择**（均衡存在性有标准结果）：以 S 为效用，P(i→k) ∝ exp(θ·S(i,k))，θ 可做敏感性；需求按概率分摊，容量做硬约束或排队截断。
3. **系统最优分配**（明确声明偏离题面行为假设）：以最大化总体目标做中心化分配。
4. **事前信息口径**（只按事前可知属性分配，S₂ 不进入选站）——必须登记为弱口径，并报告与完整满意度分配的归属差异（多少小区会换站）。

禁止：把任一口径包装成题面机制本身。选站口径分歧必须以"换站数量/方向/幅度"量化报告。

## 3. 求解算法与验证范围

- 当离散决策空间经计数确认足够小时，全枚举可作为该完整模型的精确最优性证书；更大规模可考虑MIP、分解或启发式。
- **MIP 的验证范围必须显式声明**：只建模了地理覆盖的 MIP 只验证覆盖层，不构成对"容量+分配+满意度"完整模型的证书。完整模型证书需要：全枚举（小规模）或含分配变量 x[i,k]、未满足需求 u[i]、容量约束 Σᵢ q·x + u ≥ q 的 MIP（牺牲满意度非线性层时明确声明）。
- 贪心/启发式的 gap 必须有精确参照（小规模全枚举校准），报告 gap 数值而非"接近最优"。

## 4. 档位满意度函数与定价

档位规则（按利用率/溢价率分档）是阶梯函数，两个标准效应：

- **饱和区**：若某档覆盖决策区间（如"平价及以下全部 S₃=1.0"），该区间内目标平坦，最优解由约束定界——识别饱和区可把连续优化化为约束求解。
- **档位自洽**：满意度含利用率时，S₂ 依赖分配结果。对候选档逐一解自洽方程（5 档枚举），无自洽档时登记处理方式；**不要用固定/缓存的档位值绕过校验**。
- **tie-break 是自建偏好**：题面只约束"满意度最大"时，可行解集内多个解满意度相同——此时选择的第二序/第三序（如利润率、补贴最省、价格最高）是执行者偏好，必须登记并给替代口径的方向性差异。"利润率顶格"这类结论只能以"在自建第三序下"的限定语陈述。

## 5. 财务口径

- 利润率公式按题面口径直译，但报告要**三分解**：补贴前经营利润（毛利−固定−折旧）、补贴额、补贴后净结余（现金流）。"利润为负但利润率达标"必须用三分解呈现，不得混写。
- 补贴封顶：min(单位补贴×量, 日上限×年天数) 是分段结构，封顶是否触发要单独报告。
- 免费服务是否占用非货币资源仍按题面处理；若限制明确是消费者支付上限，免费服务通常不应被该上限同比例削减。补贴资格和直接支出分别核算。

## 6. 灵敏度与情景

- **弹性与情景差分是两个量**：弹性=Δ%Δ/参数Δ%（连续近似），情景差分=离散情景的目标 pp 变化。二者可以方向不同（低基数下小幅情景可产生大 pp），不得混用排序。报告时分别命名（"情景差分"与"弹性"）。
- **组合情景与单参数情景分开**：同时改多个参数的情景只能得出"组合扰动"结论；单参数敏感性需要单独扫描。
- 情景全链重跑：下游任何数值不得沿用基线（信息时点契约）；参数化引擎（param_q1→情景字典→枚举→定价）是标准实现。

## 7. 阻断条件（优化类）

- 双目标没有排序规则就加权合并（量纲/语义未论证）；
- 档位函数被当作连续/光滑函数做梯度优化；
- 容量类约束被"结果不好看"以外的理由撤销，或放宽口径未登记为对照；
- MIP/启发式的验证范围与其声称的证书范围不符；
- tie-break 未登记为自建偏好就被写成题面结论。

## 8. 证据边界

这些模式来自真实优化题的生成与独立评审，但具体比例、容量、满意度档位和价格结构不跨题复用。每次仍以当届题面、附件和用户确认的口径为准。
