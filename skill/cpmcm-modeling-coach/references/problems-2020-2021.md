# 2020—2021年赛题结构化参考

## 使用说明

- 来源：已逐题读取 `[本地路径已脱敏]`、`2021` 中的12份正式题面，以及2020-C补充说明、2021-A附录。
- 用途：根据新题的数据形态、任务链和验证要求检索相似赛题与优秀论文；方法栏是可选路线，不代表题面指定方法或既有论文结论。
- 优先级以用户背景为准：P0与多变量时序、非线性动力系统、RC/CCM/RCM、因果机器学习、复杂网络或预测直接相关；P1适合扩展优化与机器学习能力；P2偏通信硬件或专门数值计算。
- 科学边界：没有读取数据附件时，只能判断题型与方法适配性，不能声称数据质量、论文结果或数值复现已验证。

## 2020-A：ASIC芯片上的载波恢复DSP算法设计与实现

- **输入**：16QAM通信信号；相位噪声、色散、加性白噪声；导频比例；150 Gbaud、128并行度等场景参数；加法、乘法、查表、缓存的时序和资源规则；定点位宽。
- **任务链**：设计满足RSNR代价 `<0.3 dB` 的最小导频载波恢复算法 → 量化线宽/色散与导频开销的关系 → 加入定点量化与净荷流量 `>145 Gbaud` 约束，最小化资源 → 构造性能—资源综合代价并自动优化位宽和实现结构。
- **适用方法**：导频相位估计与插值、Kalman类滤波、Monte Carlo通信仿真、定点量化误差传播、代理模型、贝叶斯/进化多目标优化、Pareto前沿。
- **关键验证**：固定随机种子和符号数；同时报告BER/RSNR、导频开销、净荷流量、位宽、基本算子数量、缓存及时序可行性；浮点与定点消融；在不同线宽和色散网格上验证。
- **更正/缺陷**：题面完整；不能只以软件运行时间替代题目定义的ASIC资源与时序核算。RSNR结果依赖具体仿真设定。
- **背景联系**：联系度3/5；可练习时序相位估计与多目标优化，但通信DSP和硬件实现门槛较高，与因果研究联系弱。
- **优先级**：P2。优先读具有端到端通信仿真、定点位宽消融和资源—性能曲线的论文。

## 2020-B：降低汽油精制过程中的辛烷值损失模型

- **输入**：325个工业样本；7个原料性质、吸附剂和产品性质及354个操作变量，共367个候选变量；285、313号原始高频样本；操作变量调节幅度；RON损失和产品硫含量。
- **任务链**：按规定方法预处理两个特殊样本 → 将主要变量降至30个以内并解释代表性/独立性 → 建立RON损失预测模型并验证 → 在产品硫含量 `≤5 μg/g` 且不可控性质固定时优化325个样本 → 展示133号样本逐步调整过程中的RON和硫变化轨迹。
- **适用方法**：稳健清洗、相关簇/PLS/PCA、Elastic Net与稳定性选择、RF/XGBoost、SHAP、RON与硫含量的多输出代理模型、约束优化、可信域或可行域投影。
- **关键验证**：所有预处理和变量筛选仅在训练折内完成；嵌套交叉验证或重复交叉验证；比较简约基线；检查优化点是否超出历史支持域、变量边界和逐步调整约束；分别验证RON目标与硫约束。
- **更正/缺陷**：325样本相对367变量属于小样本高维强共线问题。历史观测关联和模型内优化不能证明真实工艺干预会降低RON；必须标注外推风险。
- **背景联系**：联系度4/5；贴合高维统计、机器学习、解释与约束决策，也适合训练“预测不等于因果干预”的审查能力。
- **优先级**：P1。优先读能处理小样本高维、同时建模RON和硫并审查优化可行性的论文。

## 2020-C：面向康复工程的脑电信号分析和判别模型

- **输入**：5名被试的P300脑机接口数据，20通道、250 Hz、每个字符5轮刺激，训练字符12个、测试字符最多10个；另有3000条睡眠样本，每条仅含Alpha、Beta、Theta、Delta能量占比及睡眠分期标签。
- **任务链**：在不超过5轮条件下识别P300目标字符并权衡准确率/信息传输速率 → 为每名被试选择10—19个通道并形成公共通道组 → 用少量有标签样本和其余无标签样本做半监督识别 → 用尽量少的训练样本完成睡眠分期并按分类指标评价。
- **适用方法**：ERP切片与滤波、xDAWN/CSP、Riemann几何、LDA/SVM、EEGNet、稳定性通道选择、图结构通道建模、半监督伪标签/一致性学习、跨被试迁移、代价敏感分类。
- **关键验证**：按字符、轮次和被试组织分组切分，禁止同一事件邻近片段跨训练/测试；报告字符准确率、轮次数、信息传输率及个体差异；通道选择嵌套在训练折；睡眠分期报告宏F1、混淆矩阵和类别比例，不能只报准确率。
- **更正/缺陷**：补充说明指出 `S2_test_event.xlsx` 缺少 `char22` 事件，`S3_test_data.xlsx` 缺少 `char22` 原始数据，因此S2、S3的问题一和三只分析 `char13—char21`，其余被试分析 `char13—char22`。问题一不得使用问题二公开的前5个测试字符答案。睡眠附件不是原始连续脑电，不能据此研究完整睡眠动力学。
- **背景联系**：联系度5/5；直接对应多变量时序、状态表征、时空网络、少样本学习与预测，可进一步思考通道方向性，但题目本身不是因果识别任务。
- **优先级**：P0。优先读保留多通道时序结构、无泄漏、同时比较轮次—准确率—传输率的论文。

## 2020-D：无人机集群协同对抗

- **输入**：二维有限宽突防走廊；红蓝无人机和运载机的固定速度、最小转弯半径；探测与捕获规则；集群内外距离、通信、避碰和运载机安全约束；红方分波次部署能力。
- **任务链**：求蓝方无论红方策略如何都能成功突防的初始区域及策略 → 求使蓝方必能突防的通道宽度下限和最短时策略 → 优化红方两架运载机两波次数量、时刻和位置并研究红方必胜的宽度上限 → 研究3架蓝机对5架运载机、共50架红机的双方最优策略。
- **适用方法**：Dubins运动学、可达集、Hamilton–Jacobi–Isaacs方程、微分博弈、Voronoi覆盖、MPC、混合整数优化、多智能体强化学习或进化对抗仿真。
- **关键验证**：先验证单机运动和转弯约束，再验证捕获、编队、通信、避碰和发射约束；多种蓝/红策略压力测试；区分解析必胜域、数值近似域和仅在有限仿真策略下胜出；报告时间步长敏感性。
- **更正/缺陷**：题面中的公式和部分符号依赖Word图形对象，纯文本抽取会丢失，建模时须回看原文图示和参数。模型内对抗结果不是实机验证；高维情形的仿真胜率不能证明全策略空间下必胜。
- **背景联系**：联系度4/5、成长价值5/5；高度贴合非线性动力系统、复杂网络、控制和世界模型，但需要较强微分博弈与可达性基础。
- **优先级**：P0。优先读先推导可达/必胜条件、再用对抗仿真验证且明确约束的论文。

## 2020-E：探索大雾演化规律，预测大雾变化趋势

- **输入**：机场AMOS能见度、温度、湿度、气压、风速等时序；同步机场视频；无能见度仪真值的高速公路连续100帧图像；大气光学和MOR阈值知识。
- **任务链**：建立能见度与地面气象关系并导出具体关系式 → 建立机场视频监督估计模型并评价精度 → 在没有能见度标签的高速公路场景中利用景深/亮度变化估计能见度曲线 → 预测大雾加重或减弱及达到指定MOR（例150 m）的时间。
- **适用方法**：GAM、状态空间模型、RC/ESN、TCN/LSTM、CNN/视频时序融合、Koschmieder物理约束、去雾与景深估计、多模态融合、阈值首次到达模型和概率预测。
- **关键验证**：必须按时间顺序划分并设置滚动外推，禁止相邻帧随机泄漏；比较气象、单帧、连续视频和融合模型；报告MAE/RMSE、阈值事件分类、散雾时间误差和预测区间；检查视频域迁移与昼夜/光照敏感性。
- **更正/缺陷**：存档文件名“能见度估计与预测”不是正式题名，正文正式题名为本节标题。公路数据没有能见度真值，只能验证时序平滑性、物理合理性或间接一致性，不能声称绝对估计精度已被验证。
- **背景联系**：联系度5/5；直接对应多变量时序预测、RC、多模态序列和机制—数据融合。
- **优先级**：P0。优先读真正利用连续视频、气象时序和光学约束，并采用时间外推验证的论文。

## 2020-F：飞行器质心平衡供油策略优化研究

- **输入**：6个长方体油箱的尺寸、位置、初始油量、供油拓扑及速率上限；至少60秒的连续供油限制；同时向发动机/总供油箱数限制；发动机逐秒耗油、俯仰角及理想质心轨迹。
- **任务链**：计算已知供油和俯仰下的逐秒质心 → 平飞时优化供油，使实际与理想质心的最大距离最小 → 联合优化初始载油量和供油策略并保留至少1立方米余油 → 在变俯仰下使质心到空载质心的最大距离最小。
- **适用方法**：倾斜长方体内液体几何积分、离散状态空间、库存守恒、min-max优化、MILP/MINLP、动态规划、MPC、序列二次规划。
- **关键验证**：以独立几何或数值积分核对油液体积和质心；逐秒检查质量守恒、库存非负、流速、持续时间、同时供油箱数和发动机需求；报告最坏偏差、可行性残差、时间离散与初值敏感性。
- **更正/缺陷**：存档文件名缺少末尾“研究”，正文正式题名为本节标题。液面几何存在分段形态，供油开关使优化非凸；找到可行方案不等于证明全局最优。
- **背景联系**：联系度4/5；适合状态空间、动态优化和控制能力扩展，但与统计因果联系较弱。
- **优先级**：P1。优先读液体质心推导完整、所有调度约束显式且有逐秒可行性核验的论文。

## 2021-A：相关矩阵组的低复杂度计算和存储建模

- **输入**：6组相关复矩阵，均为 `M=4,N=64,L=2,J=4,K=384,σ²=0.01`；标准中间右奇异子空间V和输出W；题目规定的实数运算复杂度权重、存储位数与相位拉齐规则。
- **任务链**：利用矩阵内/矩阵间相关性，在最低V或W建模精度 `≥0.99` 下最小化计算复杂度 → 在H、W重构误差均 `≤-30 dB` 下同时降低存储和编解码复杂度 → 可选端到端联合计算与存储方案。
- **适用方法**：随机/增量SVD、子空间跟踪、跨k插值、迭代线性求解、Woodbury类恒等式、张量/低秩分解、DCT/PCA、预测编码。
- **关键验证**：按题目权重逐项统计复乘、复加、倒数等操作，并计入模型参数和推理成本；必须验证全部 `l,j,k` 中的最差精度而非只报均值；解压后执行相位拉齐；跨6组数据检查泛化和压缩误差。
- **更正/缺陷**：2021-A附录包含SVD、Strassen和随机SVD说明，应与正文联合读取。题目定义的操作权重不等于真实硬件耗时或功耗；AI方案若不计模型存储和推理复杂度则比较无效。
- **背景联系**：联系度3/5；与状态空间降维、低秩动态表征有间接联系，偏专门数值线性代数。
- **优先级**：P2。优先读逐项核算复杂度、检查最差精度并利用随k变化子空间结构的论文。

## 2021-B：空气质量预报二次建模

- **输入**：WRF-CMAQ污染物与气象一次预报；A/B/C及A邻近站长期逐小时污染物和部分气象实测；一次预报约一年、实测约两年；缺失、异常及站点字段不齐；每天7时的真实业务信息集。
- **任务链**：计算A站指定4天的AQI和首要污染物 → 按污染影响对气象条件分类 → 建立同时适用于A/B/C的未来三天六污染物二次预报，并计算AQI和首要污染物 → 利用A/A1/A2/A3建立空间协同模型并与非协同模型比较。
- **适用方法**：偏差订正、GAM/VAR/状态空间、RC/ESN、TCN/LSTM、多任务多步预测、分位数模型、时空图网络、缺失鲁棒学习、误差集成。
- **关键验证**：为每个预报起点严格重建“当日7时可获得”的实测与一次预报，采用滚动起点评估；防止未来实测、未来运行批次和同日衍生值泄漏；按站点/季节/1—3日时效报告六污染物误差、AQI最大相对误差和首要污染物准确率；协同模型必须与相同训练窗的非协同基线公平比较。
- **更正/缺陷**：气象分类与邻站相关性主要是观测关联，不能自动解释为气象干预效应或污染传播；共同天气可同时驱动邻站。AQI是污染物预测的非线性派生目标，需同时验证浓度和业务指标。
- **背景联系**：联系度5/5；与多变量时序、RC、空间网络、预测校准和观测型方向分析高度一致。
- **优先级**：P0。优先读严格遵守7时信息边界、使用滚动验证并公平检验空间协同增益的论文。

## 2021-C：帕金森病的脑深部电刺激治疗建模研究

- **输入**：附件给出的Hodgkin—Huxley神经元方程、突触连接模型和发放特征指标；Cortex、Striatum、SNc、GPe、GPi/SNr、STN、Thalamus等核团及直接/间接通路；直流、交流和高频刺激参数。
- **任务链**：模拟单神经元在外界刺激下的放电并提取指标 → 每个核团以5—10个神经元构建基底神经节回路 → 比较健康回路与去除SNc的PD回路 → 比较STN和GPi刺激并优化强度、频率、模式 → 搜索直接或间接通路中的其他刺激靶点。
- **适用方法**：非线性ODE与稳定数值积分、尖峰检测、发放频率/同步性/谱指标、耦合动力网络、分岔分析、参数敏感性、多目标刺激优化、网络可控性辅助分析。
- **关键验证**：先复现单神经元静息和受刺激响应，再验证突触符号与网络连接；检查时间步长和积分器稳定性；用多个初值、噪声和生理参数做敏感性分析；靶点比较必须使用一致的刺激能量与疗效指标，并报告副作用或能耗代理。
- **更正/缺陷**：题面完整，但疾病态被简化为去掉SNc，核团也被缩减至极少神经元。模型内删除节点或施加DBS属于机制模型内干预，不等于临床Pearl `do`效应、真实疗效或最佳靶点已验证。
- **背景联系**：联系度5/5、成长价值5/5；是非线性动力系统、复杂网络、机制建模和模型内干预的最佳切入题。
- **优先级**：P0，建议首批第一题。优先读方程复现完整、网络连接透明、刺激敏感性和靶点比较严格的论文。

## 2021-D：抗乳腺癌候选药物的优化建模

- **输入**：1974个化合物的SMILES、729个分子描述符、ERα活性IC50/pIC50和5项ADMET二分类标签；另有50个无标签测试化合物。
- **任务链**：筛选并排序影响活性的前20个描述符 → 用不超过20个变量建立活性回归并预测测试集 → 分别建立Caco-2、CYP3A4、hERG、HOB、MN分类器 → 寻找兼顾高活性和至少3项良好ADMET的描述符及取值范围。
- **适用方法**：Elastic Net、稳定性选择、RF/XGBoost、分子骨架或结构簇切分、嵌套交叉验证、多任务分类、校准、SHAP/PDP、desirability或Pareto筛选。
- **关键验证**：变量筛选必须位于训练折内部；优先按分子骨架/相似簇划分以测外推能力；回归报告MAE/RMSE/R²，五个分类任务分别报告ROC-AUC、PR-AUC、F1、校准和类别比例；解释结论需检查共线性与跨折稳定性。
- **更正/缺陷**：存档文件名误写“抗胰腺癌”，正文正式题名为“抗乳腺癌候选药物的优化建模”，靶点为ERα。描述符区间是观察关联，不等于改变结构后的因果效应；测试集没有真值时，产生预测文件不能视为外部验证。
- **背景联系**：联系度4/5；贴合高维统计、机器学习和解释，但时序/动力系统成分弱。
- **优先级**：P1。优先读采用结构外推划分、严格嵌套选择并检验解释稳定性的论文。

## 2021-E：信号干扰下的超宽带（UWB）精确定位问题

- **输入**：场景1中4个已知锚点、324个Tag固定坐标；每个位置分别采集正常和遮挡干扰的多组TOF距离，共648个文件；场景2采用不同空间尺寸和锚点高度；另有未知干扰样本和动态轨迹时序。
- **任务链**：解析原始文本并清洗重复、缺失和异常样本 → 分别建立正常/干扰3D定位模型并报告1D、2D、3D精度 → 将同一模型迁移到新几何场景 → 判别信号是否受干扰 → 联合干扰判断与运动规律恢复动态轨迹。
- **适用方法**：加权非线性最小二乘、多边定位、NLOS正偏差建模、RANSAC/M估计、RF/XGBoost干扰分类、Kalman/粒子滤波、切换状态空间/HMM、物理—数据混合模型和跨场景域适配。
- **关键验证**：必须按Tag位置或整个文件分组切分，不能将同一点的连续重复测量随机分到训练与测试；分别报告正常、干扰、混合和跨场景误差；检查几何约束、残差分布、异常分类校准；动态轨迹比较无滤波、普通滤波和干扰感知滤波，并报告连续性和边界约束。
- **更正/缺陷**：题面完整。同一点有大量重复测量，按行随机划分会严重泄漏；场景2只有10组待预测样本且题面未给真值，无法仅凭提交坐标证明普遍跨场景泛化。
- **背景联系**：联系度5/5；直接对应多变量传感时序、状态空间、异常检测、动态预测与机制约束，可与RC比较动态滤波能力。
- **优先级**：P0。优先读几何定位、干扰误差模型和动态状态估计真正联动且无位置泄漏的论文。

## 2021-F：航空公司机组优化排班问题

- **输入**：航班时空网络、最低机长/副机长配置、机组基地和资格、乘机许可、执勤/任务环成本；连接、执勤、飞行、休息、连续执勤和休假约束；A套206航班/21人，B套13954航班/465人。
- **任务链**：直接给航班分配机组并按优先级最大化覆盖、减少乘机和替补 → 加入执勤成本、时长限制和公平性 → 加入任务环成本、周期总时长、休假和连续执勤限制，形成完整排班并输出未覆盖航班和机组日程。
- **适用方法**：时间—空间网络、MILP、集合划分、字典序优化、列生成、拉格朗日松弛、Benders分解、大邻域搜索、滚动时域和启发式热启动。
- **关键验证**：逐条自动审计机场连续、时间连接、每日执勤、飞行/执勤上限、休息、基地闭环、资格配置、乘机上限和休假；严格实现题目给定的目标优先序；A套用于正确性，B套用于可扩展性；报告可行性、目标分层结果、最优间隙和运行时间。
- **更正/缺陷**：题面目标编号表达的是字典序优先级，未经严格界定的加权和可能改变优先关系。A套成功运行不能证明B套可扩展；启发式可行解不能直接称为全局最优。
- **背景联系**：联系度4/5、成长价值5/5；贴合调度、图网络和大规模组合优化，可补强用户的运筹优化能力。
- **优先级**：P1。优先读目标优先序实现严格、约束显式并真正跑通B套大实例的论文。
