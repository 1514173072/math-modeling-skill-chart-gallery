# 论文交付前独立评审与自迭代

本流程只用于“生成完整竞赛论文并交付”的任务。方案讨论、单项计算、已有论文只读评价不自动触发。

## 状态机

`候选稿完成 -> 统一质量门 -> 冻结评审包 -> 独立选择优秀论文基准 -> 独立子智能体盲审 -> 问题处置 -> 修订与全链重跑 -> 定向复核 -> 最终交付`

候选稿完成后只能称“候选稿”，不能立即回复最终交付。先按 `paper-quality-gates.md` 核对统一章节、正文页数、引用覆盖、代码位置和图表排布；未达到确认页数时必须完成一次证据型扩写，第二轮仍不足则暂停请示，不能进入最终交付。每个状态保留版本、路径和时间；不需要用哈希证明文件发生变化。

## 冻结评审包

第一轮评审只提供：

1. 真实题面、补充说明和当届格式规范；
2. 附件清单、可用状态和必要字段说明；
3. 冻结的候选论文；
4. 支撑核心主张的代码、结果工件和主张—证据矩阵（若可用）。
5. 评审者独立选出的3—5篇相似优秀论文及 `assets/benchmark-selection-template.md` 记录。

不要提供作者自审报告、已有外部评分、预期分数、已知缺陷清单或拟定修复方案。第一轮盲审完成后，主执行者再把独立报告与作者自审交叉核对。

## 优秀论文基准选择

基准由未参与候选稿生成的评审者选择，生成者不能把希望模仿的论文或预设结论直接塞给评审者。评审者先从题面建立任务画像，再查询问题地图、匿名索引和精读笔记；真正用于基准评分的论文必须由用户提供或在当前环境中合法可读，并实际读取原PDF相关章节、记录页码。只有笔记而没有原文时，不得声称完成原文级基准评审。

动态选择3—5篇，至少覆盖：题型或数据结构相似、方法与验证相似、写作与图表表达三种角色。基准论文只用于比较题意覆盖、证据密度、选模理由、验证、图表、引用和语言，不复制其文字、数值、代码或结论，也不因优秀论文自身存在缺陷而放宽科学标准。

## 独立评审者职责

评审者不得参与过候选稿生成，默认只读，不直接改论文。先从题面独立建立要求表和基准选择记录，再沿以下链条核对：

`题面要求 -> 数学模型 -> 代码实际实现 -> 验证模型 -> 结果工件 -> 论文结论`

每个问题必须包含：问题ID、P0/P1/P2严重度、题面或证据指针、对应位置、影响的下游结论和可验证关闭标准。没有证据指针的意见只列为建议，不能自动触发大规模重写。

使用 `assets/independent-review-template.md` 分别输出工程复现分、科学有效性分、综合分及区间、修复后潜在分、交付阻断项和未核验风险。存在未关闭的核心定义、泄漏、硬约束、关键复算或其他科学P0时，综合分不得超过84。

高风险统计量的独立复算必须从定义、真实标签和冻结预测/结果重新实现，不得导入、复制或改名复用作者的评价函数。独立程序复现同一结果只证明内部一致；还要检查实现是否符合统计定义、选择过程是否被完整嵌套、抽样与不确定性解释是否成立。

评审者必须查看最终PDF渲染页，核对图表堆叠、表意、图文引用、裁切、字号、代码位置和残留标记。若当前评审者无法做视觉检查，应增加独立视觉检查并在报告中标明责任人；不能在未查看最终页面时给表达与格式高分。

## 主执行者处置与修订

对每项问题记录“采纳、部分采纳、不采纳”及理由。不采纳必须给反证，不能因已投入工作量或作者自审通过而拒绝。

修订顺序为：

`题面与约束契约 -> 数学模型 -> 代码 -> 结果工件 -> 主张—证据矩阵 -> 论文文字与图表`

P0涉及题意、硬约束、数据泄漏、核心定义或关键复算失败时，从最早受影响层修复，全部依赖结果失效并重跑。禁止只改措辞掩盖模型或代码错误。P1在证据支持时修复；P2按时间和用户偏好处理，不为追分堆模型、堆图或扩页。

## 复核与停止条件

修订后由原独立评审者定向检查原问题ID的关闭标准，并只补充修订新引入的P0。默认一次完整盲审、一次修订和一次定向复核；仍存在核心问题时可再进行一轮完整评审，但除非用户另有要求，最多两轮完整评审。

满足以下条件才进入最终交付：

- 无未解决P0；
- 无会改变核心结论且已采纳但未处理的P1；
- 上游变更后的下游结果、图表和正文已经重跑或重生成；
- 关键主张、匿名/格式和最终PDF渲染通过终检；
- 正文页数达到用户确认下限，或已有用户明确接受短稿的记录；
- 参考文献达到覆盖门并默认不少于15篇，完整源码位于论文PDF之外；
- 残余风险、未复现部分和降级结论已明确披露。

停止目标是证据闭环，不是达到某个分数。证据、时间或权限不足时，降级结论并交付限制说明，不进行无止境改写。

## 环境不支持子智能体

执行作者自审并明确标注“独立评审未执行”。主执行者的第二次自检不能冒充独立评审，也不能把作者自审分数写成外部评价。
