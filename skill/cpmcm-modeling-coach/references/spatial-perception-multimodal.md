# 空间感知、路径与多模态建模

## 适用范围

用于平面图、DWG/PDF/JPG、矢量坐标、照片或视频共同描述空间布局，且任务同时涉及可通行路径、视域变化、空间体验、审美/舒适度等潜在构念的题目。它连接几何处理、图网络、空间统计、多指标评价与多模态验证；不能把其中任一层的高分直接当成“美学真值”。

## 输入与几何契约

先建立统一空间数据字典：坐标系、原点、单位、比例尺、元素类别、点/线/面类型、线段分隔符、闭合状态、高度或冠径、遮挡属性、可通行属性和来源文件。平面图、矢量表、照片与视频之间的对应关系必须可追溯。

几何清洗至少检查重复点、断裂线、伪交点、自交、多边形闭合、洞、孤立分量、比例尺和坐标方向。实体墙、水体、山石等障碍与半开放建筑、道路、植物冠幅不能用同一通行/遮挡规则。人工修补必须记录原始几何、修补原因和敏感性版本。

## 从几何到路径

按 `可通行区域 -> 骨架/候选节点 -> 合法边 -> 加权图 -> 路线` 形成可复算链：

- 结构化路网直接以转折、交叉、入口、出口和关键景点为节点；
- 复杂自由空间可用栅格、可见图、中轴/骨架、Voronoi或Delaunay候选连接，但所有边必须通过障碍相交和最小通行宽度检查；
- 保存节点坐标、边几何、长度、转折角、通行类型和来源，不只保存邻接矩阵；
- 基线使用最短合法路线或简单覆盖路线，再根据任务加入重复率、转折、景观变化和拥挤等目标。

“趣味性”不等于路径越长、转折越多。可将路径长度、分岔/环路、覆盖率、重复率、转折频度和沿途可见元素变化组成测量模型，但需给方向、量纲、饱和或惩罚逻辑。游线优化通常是多目标问题，应输出Pareto方案或明确的字典序，并展示多条路线的差异与适用游客偏好。

## 空间布局与感知序列

元素分布可从数量、面积占比、最近邻、离散度、Shannon熵、Ripley K、分形维数、边缘密度、聚集度和空间句法等候选中选择；只保留与构念有明确关系且对尺度/采样稳定的指标。高度相关或同义指标先分组、消融或降维，不靠数量堆出综合分。

开阔/围合应沿真实游线形成序列，可结合视线通透率、可见天空、障碍高度、空间宽高比、可见元素比例及相邻位置变化。平面坐标不支持高度结论时必须降级；照片采样不均时不能把照片数量当空间出现频率。重点分析“连续感知如何变化”，而不是只给全园平均值。

## 评分与相似度

若以某对象固定为100分，它是题面规定的规范性锚点，不是实证金标准。综合评分先写出构念—指标映射、正负方向、标准化、权重来源和补偿规则，再做权重、阈值、采样尺度与缺失元素敏感性。权重可来自文献、专家或训练数据；信息熵等数据权重反映离散程度，不自动代表审美重要性。

多模态相似度按“特征块”建模：路径/图结构、元素布局、开合序列、图像或文本语义分别标准化并先做块内诊断，再讨论块间融合。余弦、Jaccard、最优传输、图核或学习嵌入承担的对象不同；至少与透明距离基线比较。UMAP、聚类树和热图用于解释结构，不作为真实性证明。

新增文化或审美维度必须可操作化并有外部依据。例如借景性、写意性、虚实关系或时序变化可以提出候选指标，但需说明数据能否观测、代理误差和适用边界，不能因名称有文化含义就认为测量成立。

## 验证链

1. 几何层：抽样回查原图，验证拓扑、障碍、入口出口和比例尺。
2. 路径层：检查连续、无穿障、覆盖/重复口径和目标值独立复算。
3. 感知层：用照片、视频、现场记录或人工标注核对可见性与开合变化。
4. 构念层：以独立专家/游客评分、成对比较或可靠文献验证指标方向；无此证据时称“模型内指数”。
5. 稳健性：改变采样间距、栅格尺度、几何修补、权重和算法，报告路线/排名/邻居是否变化。
6. 泛化：将冻结流程应用到至少一个未参与设计的外部空间，既报告支持例也报告反例。

外部对象必须在指标、权重和阈值冻结后进入；先看外部结果再调整方案不能称外部验证。若不同模态覆盖对象不同，按共同对象和缺失机制评价，不能把缺失填成零后直接比较。

## 结果资产与图表

保留清洗前后几何、节点/边表、路线坐标、逐点/逐段感知序列、特征矩阵、权重与标准化参数、相似度矩阵、外部测试结果和敏感性结果。主图可选合法游线叠加异景强度、开合度随距离变化、元素分布地图、相似度热图与聚类树；每张图必须指向真实坐标和结果字段。

## 阻断与降级

- 坐标单位、线段结构或障碍属性无法确认时，不输出精确路线；
- 图由简单近邻连接生成却未做穿障检查时，不称可通行路网；
- 只有平面图却声称真实视域、高度遮挡或沉浸体验已验证；
- 单一余弦相似度、单一综合分或UMAP分离不能证明共同美学规律；
- 没有独立主观评价时，使用“模型内趣味性/幻境感指数”，不称客观审美评分；
- 未冻结方法前使用外部园林调参时，不称泛化验证。
