# 全文证据驱动的方法地图

本地图从首批 `full_read` 笔记沉淀竞赛决策规则。它不是优秀论文方法投票，也不把作者自报指标当作复现结果。需要追溯时，用 `scripts/search_full_read_notes.py` 搜索文中 `paper_id` 或方法关键词，再读取对应逐篇笔记。

## 先确定四个对象

在选模型前写清：

1. **独立数据单位**：患者、受试者、字符、原始信号、视频、完整天气事件、日期、站点还是空间区域。
2. **业务信息时点**：在每次预测或决策时，哪些列已经可见，哪些只在未来或结局后产生。
3. **可评价真值**：题目给的是正式标签、代理真值、仿真输出、无标签目标域还是纯情景假设。
4. **最终行动对象**：输出只是解释/预测，还是会进入选址、调度、治疗、开放策略或路线规划。

这四项决定切分、指标和语言。模型复杂度排在其后。

## 从测量到决策的三层闭环

竞赛论文常直接展示最终策略，实际应分别验收：

`原始观测 X -> 测量/状态 Z -> 预测或风险 R -> 决策 A -> 约束与结果 Y`

- **测量层**：图像车辆数、雾距离、雷达格点、患者时间、疲劳循环是否有真值、单位和标定。`参考论文_28_2024E`未先量化检测/跟踪误差，后续高`R²`不能弥补测量层断点。
- **预测层**：只使用行动时点可见信息，并在独立单位上评价。`参考论文_06_2021B`先全序列标准化、随机拆重叠窗并用测试集调参，是典型失效链。
- **决策层**：把预测误差传入约束/目标，报告可行率、风险和相对基线。`参考论文_26_2024A`文字称连接前两问，但优化式实际上未调用Goodman/Miner和载荷模型，属于接口只存在于叙述。

任一上游层没有验证，后续层的精确优化只是在错误输入上更精确。

代理标签必须在测量层单独验收。用经验公式、阈值或已有模型生成“湍流强度”等标签，只能证明后续模型学会了该代理规则；除非用独立仪器、人工标注或外部数据校准，不能称为真实物理量验证（`参考论文_29_2025D`、`参考论文_30_2025D`）。同理，用随机坐标扰动扩增观测点不会产生新的空间信息，不能替代真实站点覆盖、空间交叉验证或不确定性传播。

## RC/ESN 的使用门槛

优先考虑RC/ESN的情形：

- 非线性动态明显，但有效独立样本少，训练大型深网不稳；
- 需要快速滚动重训、在线更新或大量超参数/情景比较；
- 目标是预测或状态表征，且可以用统一读出层连接后续优化；
- 需要与LSTM/TCN/Transformer在同一数据协议下提供低成本强基线。

首批已读论文中没有一个可以作为“RC/ESN已成功复现且优于基线”的案例；这里是由题型结构和已发现的验证失败推导出的选模规则，不是历史优秀论文已经证明RC更优。

至少报告：输入缩放、储备池规模、稀疏度、谱半径、状态泄漏率（leaking rate）、洗出期、读出正则、随机种子和滚动误差。多站点RC还要说明是共享储备池、站点特定读出还是图约束读出。

不应使用RC/ESN来替代：

- 已知且可校准的守恒/生理机制；此时它更适合作残差或代理模型；
- 没有时间顺序或有效序列长度的表格任务；
- 直接证明因果。RC预测能力、跨变量重构或模型内断边不是现实`do`效应。

## GNN、时空注意和扩散的使用门槛

- **GNN**：节点、边和权重必须有物理来源或只在训练数据内学习，并对删边、随机图、距离图等基线做消融。只有四个站点且`SE`来源缺失时，复杂图网络通常不比清楚的站点基线更可信（`参考论文_12_2021B`、`参考论文_06_2021B`）。
- **时空注意**：适合长序列、多站点、多提前量，但不因“注意力”而自动可解释。注意权重、SHAP和输入消融只说明模型依赖。
- **扩散/生成模型**：适合需要多种未来和概率场的任务；必须报告多次采样、概率评分、校准、覆盖和极端尾部。只给单张视觉结果或通用框架代码，不能证明条件扩散闭环已实现（`参考论文_23_2023F`）。

## 无标签目标域与信号切窗

- **先分组，再切窗**：冻结原始文件、轴承实体、试验批次或工况所属集合，再只在集合内部切窗。相邻重叠窗口跨训练/测试会共享采样点和背景工况，窗口级高分不能代表跨设备泛化。
- **源域先独立过关**：迁移前先在未见原始文件或设备上报告源域性能，并保留不迁移、仅标准化、传统特征等基线；否则迁移结果可能只继承源域泄漏。
- **对齐不等于分类正确**：t-SNE混合、MMD下降、域分类器接近随机、伪标签内聚或置信度稳定，只是间接证据。还要检查类条件对齐、类间间隔、物理故障频率、不同种子稳定性、文件级聚合和未知类拒识。
- **目标标签不可偷用**：真正无监督目标域不能用目标真值逐轮选epoch、调超参数或决定模型。若仅为赛后审计而查看标签，应与建模流程物理隔离，并明确这是封存评价。
- **无真值时的输出边界**：可以给候选标签、置信区间、稳定性、跨方法一致性与物理一致性；不能把这些指标写成目标准确率或已经证明的故障类型。至少需要少量盲标目标样本、跨设备已知标签集或独立台架数据，才能估计泛化误差。
- **实现审计**：正文中的MMD、域对抗或对比损失必须保持梯度并实际进入总损失；写出公式、打印数值或在训练后单独计算，不代表模型用它优化。类别数、聚类数、权重加载、窗口到文件的聚合规则也必须与正文一致。

上述规则来自三篇2025-E精读中反复出现的断点，不表示这些论文的迁移结果已经复现。

实施顺序必须是：先建立稳定的患者/被试/事件/日期ID并冻结集合，再在各集合内部生成窗口、切片、伪标签和重采样；先生成高度重叠样本再随机切分，无法靠后续去重补救。

## 因果语言决策树

1. 只比较未来预测误差？写“预测增益”。
2. 用传递熵、CCM/RCM或有向分数？写“观测动态方向”；检查采样、稳定性、共同驱动和收敛。
3. 删除特征、替换输入、设置极端状态或模型内断边？写“模型情景/消融”。
4. 比较治疗、政策或开放策略？先给处理、结果、时间零点、混杂、识别假设和估计量，满足后才写“干预效应”。
5. 声称个体未发生世界？需要结构模型和跨世界可识别条件，满足后才写“反事实”。

证据边界例：

- `参考论文_24_2023F`的传递熵可用于候选方向图，不能自动升级为因果贝叶斯网络、软干预和反事实。
- `参考论文_17_2022F`的政策前后LSTM轨迹是预测情景，不是政策因果效应。
- `参考论文_28_2024E`把出流乘1.3得到拥堵时间下降，只是`what-if`情景。
- `参考论文_21_2023E`的治疗频数、相关热图或不完整混合模型不能解决适应证混杂。

## 选模停止规则

在同一验证协议下逐级推进：

1. 数据和测量层不可靠：停止加模型，先修字段、单位、标签和切分。
2. 透明基线已达到业务容差：保留它作为主模型，复杂模型只在稳定增益或额外能力明显时加入。
3. 复杂模型只改善单一平均指标，却损害尾部、校准、可行率或运行时间：不升级。
4. 正文主张无法由公式/代码映射：可以重建思想，不能继承作者指标。
5. 无独立真值：报告代理指标和不确定性，不生成准确率、疗效或“最优”结论。
6. 代理标签或随机空间扩增没有外部校准：停止把后续拟合优度解释为物理有效性，先补测量验证或降低结论层级。

停止升级模型后，按 `method-routing.md` 的“负结果组织”保留下界、失败范围、合理尺度或稳定规律；停止不是删除不利结果。

## 缺数据时的复现输出

没有附件时仍可交付：

- 逐问模型链和公式/参数可重建清单；
- 正文—附录—代码差异表；
- 冻结的数据切分与信息时点契约；
- 最小数据请求、环境请求和中间校验值；
- 可运行的合成数据单元测试或接口骨架，但必须标明不代表作者数值复现；
- 明确阻止状态升级的条件。

详细请求顺序见 `references/reproduction-audit.md`。
