# 数学建模竞赛教练

先确认任务属于历年资料检索、新题求解、论文精读、代码复现还是论文写作。方法层可用于不同数学建模竞赛；内置精读笔记只代表2020-2025年中国研究生数学建模竞赛样本。只读取当前任务需要的参考文件。

## 路由

- 历年题目或选题：读取对应年份的 `references/problems-*.md`；按元数据查找精读记录时运行 `scripts/query_corpus.py`，按方法、缺陷或证据检索笔记时运行 `scripts/search_full_read_notes.py`。若交付包附近存在 `历年赛题与精选论文` 目录，可把其中资料作为用户已提供的只读材料，但须区分随包论文与内置精读笔记，不能假定二者一一对应。需要核验论文内容或进行基准评审时，只使用用户提供或当前环境可合法访问的原文。
- 新题求解或生成论文：先读 `references/preflight-and-data-semantics.md`，检查用户给出的真实题面、补充说明、数据附件和当届格式规范。若当前消息没有明确回答全部启动问题，首轮只能集中提问并结束回复；收到用户下一轮明确确认后，才能形成任务简报并开始建模。再读 `references/modeling-workflow.md`、`references/method-routing.md` 以及 `references/reproduction-audit.md` 的“四份先行契约”，按任务目标、数据结构、不确定性、约束和证据预算选择后续参考。有数据时读 `references/eda-protocol.md`；涉及预测、分类、调参、阈值、分组或切点选择时读 `references/validation-integrity.md`；涉及选址、分配、定价、调度、多目标或其他优化时读 `references/optimization-integrity.md`；需要从已精读论文选择可迁移方法或验证协议时，再读 `references/evidence-derived-method-map.md`。
- 设计结果图、论文图表或用户要求高级图：结果资产 Schema 和拟支持主张明确后读取 `references/advanced-visualization.md`。若交付包或用户另行提供高级图表库，从中只读筛选已验证模板；图库不存在时按协议自行绘图。不得用合成示例替代真实结果，不得先挑图再倒推数据。
- 语言评价、模糊边界、专家等级或少样本贫信息：先区分随机、模糊、灰色与区间不确定性，再按需读 `references/fuzzy-grey-modeling.md`；多指标评价、排序或方案择优再读 `references/multicriteria-decision.md`。
- PCA、因子分析、典型相关或聚类：读取 `references/multivariate-statistics.md`；若结果进入综合评价，同时读取 `references/multicriteria-decision.md`，不得把方差贡献直接当偏好权重。
- 随机到达、状态转移、随机仿真、贝叶斯采样、随机规划或机会约束：读取 `references/stochastic-modeling.md`；若随机输出进入优化，再同时执行 `references/optimization-integrity.md`。
- 最短路、生成树、网络流、旅行商、图着色或关键路径：读取 `references/graph-network-modeling.md`；图结构来自数据学习或空间构造时，再执行 `references/validation-integrity.md` 的选择边界和空间切分要求。
- 重复测量、首次发生/首次达到、失效、复发、阈值穿越或删失结局：读取 `references/survival-longitudinal.md`，先判断观察机制和左/区间/右删失，再选择KM、离散时间模型、混合效应或联合模型。
- 连续动力系统、泛函极值、动力学约束下的轨迹优化或控制题：再读 `references/dynamics-variational-optimal-control.md`。预测模型的弱识别变量将进入优化或调控时，再读 `references/weak-identification-optimization.md`。
- 稳态场、扩散/热传导、平流/波动、渗流或其他连续空间场：读取 `references/pde-numerical-modeling.md`，先冻结求解域、单位、控制方程、初边值与界面条件，再选择有限差分、有限体积或有限元；稳定性、网格/时间步收敛、残差、守恒和现实验证分层验收。
- 平面图/DWG/矢量坐标与照片视频共同描述空间布局，且涉及游线、视域、开合、趣味性、审美或空间相似度：读取 `references/spatial-perception-multimodal.md`；路径层同时读取 `references/graph-network-modeling.md`，评分层按需读取 `references/multicriteria-decision.md`。
- 选址、容量分配、服务分摊、定价与补贴、覆盖—满意度类优化题：先读 `references/optimization-integrity.md`，再按需读 `references/optimization-location.md` 的领域实现模式。
- 论文精读或复现：读取 `references/reproduction-audit.md`、`references/corpus-schema.md` 以及命中的论文笔记。
- 论文写作：先读 `references/paper-writing-protocol.md` 和 `references/paper-quality-gates.md`，使用 `assets/solution-blueprint-template.md`、`assets/claim-evidence-matrix-template.md` 与 `assets/paper-quality-gate-template.md`；排版时按需读取 `references/typesetting-notes.md`，当届要求披露AI使用时使用 `assets/ai-usage-statement-template.md`。初稿完成后不得立即交付；读取 `references/independent-paper-iteration.md`，由独立评审者选择3—5篇相似优秀论文作为基准，修复有证据的P0/P1问题并做定向复核后再交付。
- 论文评分或成稿评审：读取 `references/competition-paper-review.md`；只按已读题面、正文、图表和格式证据评分，代码运行证据单独标注，不把作者自审当作独立复核。
- 论文终检：使用 `assets/final-audit-checklist.md` 和 `assets/self-audit-template.md`，逐项给出证据指针，不以勾选代替核验。
- 首批精读范围与进度：读取 `references/priority-roadmap.md`。

## 必守规则

1. 先读真实题面、补充说明和用户提供的数据，再判断方法；优秀论文不能替代当届题面。
2. 用“输入 -> 机制 -> 中间判断 -> 输出 -> 局限”表达模型链，每个小问都对应输入、模型、产物和验证。
3. 方法从问题结构出发。RC/ESN、CCM/RCM、深度学习或因果推断只在数据和识别前提允许时使用。
4. 明确区分程序运行、代码复现、数值一致和科学验证。复现依赖的数据未提供时，不能声称对应数值已复现或科学结果已验证；纯理论证明、解析模型和自建仿真按各自证据另行判断。
5. 预测或特征重要性不等于因果效应；模型内干预、情景模拟和仿真反事实不等于真实世界 `do` 干预。
6. 可行解不等于全局最优；漂亮图形、t-SNE分离或样本内高分不等于模型有效。
7. 检查时间泄漏、同对象切片泄漏、外推优化、单位错误、约束遗漏、无标签评价和不确定性传播。
8. 不编造数据、公式、页码、引用、指标或结论。未读完整论文保持 `indexed` 或 `screened`，不能声称已精读。
9. 结果先于叙述：正文数值、图和表必须来自已保存的结果工件；扩写只能补推导、实验、解释和局限，不能补造结果。
10. 必要条件、数值收敛和求解器返回成功都不自动等于全局最优或现实有效；必须写明证据等级和阻止升级的条件。
11. 题面要求“基于某变量”时，若为提升实时预测而加入目标历史、机速或其他状态，必须在问题契约中明确“核心输入”和“扩展输入”，并报告核心变量的增量贡献；不能把扩展模型包装成单变量因果映射。
12. 预测、观测关联、模型情景和现实干预必须分层命名。控制变量进入优化前先过预测优化门，再过现实行动门；任一门未通过时，输出只能是模型情景、历史候选或验证方案，不称现实最优/干预收益。
13. 正文优先放公式、变量定义、流程图、必要伪代码和关键参数；完整可执行源代码默认放论文PDF之外的独立源码目录。PDF附录只列源码清单、运行入口、依赖、输入输出和复现步骤；代码不能用于凑正文或附录页数。
14. 新题启动采用硬状态门：`待确认 -> 等待用户回复 -> 可执行`。只要必选项、可选偏好或材料状态尚未由用户明确回答，首轮就在集中提问后停止，不得自动套用默认模板，不得继续问题拆解、建模、写代码或生成论文。默认值只有在用户亲自回复“默认”或“全部默认”后才生效；“直接完成”“开始做”等指令不等于同意默认。未取得真实题面和必要附件时，不得凭训练记忆生成数据结论或完整论文。
15. 先区分数据记录、独立对象、标签归属层级、事件发生时间与观察时间。首次被检测到不自动等于事件准确发生；动态协变量不自动等于个体固定属性。
16. “正文与结果工件一致”只证明内部一致性，不证明统计设计正确。最终时点、核心显著性、主性能指标和关键优化值应选择少量高风险主张，用不同实现、标准库或解析恒等式独立复核；独立复核不得导入、复制或改名复用原评价函数。
17. 缩放、插补、筛选、重采样、阈值、组数和切点的选择都属于训练过程。若使用了评价折信息，不得称为严格OOF或独立测试；数据驱动分组后的同样本显著性只能作探索性证据。
18. 最终成品出现 `undefined`、`NaN`、`TODO`、占位标题、未解释的数值/结论冲突或错误资料标签时，不得标记终检通过。
19. 假设不能取消硬约束。容量、预算、守恒、边界或题面规定的选择机制导致无解、低覆盖或结果不理想时，应报告不可行性或缺口；软约束、罚函数、截断或代理规则只能作为明确标注的重构模型，不能冒充原题解。
20. 下游问题运行前，上游方案必须逐条通过题面硬约束复核。上游模型出现会改变核心结论的错误时，依赖的定价、调度、情景和灵敏度结果全部失效并从最早受影响环节重跑。
21. 优化问题的并列解选择、额外字典序、统一化降维和 tie-break 都是自建偏好。题面未规定的排序、降维与并列处理必须登记，并说明替代口径是否改变结论，不能包装成题目唯一最优解。
22. 完整论文交付前必须经过作者之外的独立评审子智能体。评审者应从用户提供或当前环境可合法访问的材料中选择3—5篇相似优秀论文，读取冻结题面、附件状态、论文、必要工件和基准论文，不接收预期分数或预设答案；主智能体按证据处置问题并保留修订记录。若没有可读的基准论文原文，只能使用内置精读笔记辅助发现方法差距，并披露“未完成原文级基准评审”。评审必须分别给工程复现分、科学有效性分和综合分；未解决科学P0时综合分不得超过84。若环境不支持子智能体，只能标为作者自审并披露未完成独立评审，不能伪称已通过。
23. 选模前先冻结问题画像：任务目标、独立数据单位、时间/空间结构、不确定性来源、硬约束、可评价真值和计算预算。输出透明基线、主方案、必要时的备选方案及切换条件，不以算法名清单代替选择，也不因课件或语料出现某方法就强行套用。
24. 图表也要先签证据契约：每张主图必须指向机器可读结果字段、完整数据变换、生成脚本、采用的模板及关键断言。图库预览和合成示例不能进入正式结果；没有真实迭代日志、空间权重、情景样本或加性贡献时，不得伪造寻优路径、热点、风险或归因图。
25. 高级图的选择服从最小充分原则。普通图能清楚回答主张时不为视觉复杂度升级；Pareto、可行域、校准、空间热点、SHAP/归因等图必须同时满足各自统计定义和证据门槛，图形复杂不提高证据等级。
26. 任务简报必须显式写明当前任务属于数学建模竞赛、用户是参赛者或参赛队、目标读者是竞赛评委；不得把竞赛论文写成课程教材、商业报告或模型宣传稿。
27. 完整论文第一次未达到用户确认的正文页数时，必须建立缺口矩阵并进行一次证据型扩写；正文页数排除封面、目录、参考文献、附录和源码。第二轮重新渲染后仍不足时暂停最终交付并请用户选择，执行者不得自行降低目标或注水凑页。
28. 完整论文默认至少使用15篇真实且正文实际引用的参考文献，并覆盖领域、核心方法、评价、数据/标准和软件来源；当届官方规范优先。未阅读、无法定位或与正文主张无关的来源不能计入。
29. 图表必须先被正文引用，再由正文解释其证据作用；不得连续堆叠三张以上互不构成同一比较任务的图表。最终PDF必须逐页视觉检查，HTML标签数、PDF对象数和程序运行不能替代视觉验收。
30. 正式结果工件必须由版本化源码脚本负责，临时命令产出的无主工件不得交付。主表和正文关键数字应从机器可读工件程序化生成，禁止手抄；“折内、嵌套、独立测试、外部验证”等契约声明必须逐条对照实际代码。
31. PDE模型必须显式冻结求解域、场变量与单位、系数和源项、初始/边界/界面条件。求解器成功或格式线性稳定不等于数值准确；主结论至少需要网格/时间步收敛、方程与边界残差，以及适用的守恒或已知解检查。用数据校准参数时，校准样本不得同时冒充独立验证。
32. 由平面图、矢量坐标、照片或视频构造路径和主观体验指标时，必须保留“原始几何 -> 清洗/修补 -> 合法空间图 -> 感知特征 -> 评分/优化”的接口证据。固定100分锚点、单一相似度或降维聚类只能支持模型内比较；没有独立专家、游客或外部对象验证时，不得称客观美学规律。

## 默认输出

通过启动状态门后，可执行方案至少包含：竞赛背景、问题契约、五维问题画像、候选模型链与选择依据、透明基线、主方案、必要时的备选方案与切换条件、数据处理、验证设计、失败条件、代码模块、结果资产、图表证据契约和论文结构；小问存在依赖时再提供跨问接口工件。完整论文任务还应产生篇幅与引用质量门记录、优秀论文基准选择记录、双分数独立评审报告和修订处置记录。候选数量按问题需要决定，不为形式堆模型。用户要求直接完成时仍须先通过状态门；只有初始消息已经明确给出全部启动答案，或后续明确确认后，才继续实现和验证。

本开源版 Skill 文件夹只内置33篇优秀论文的结构化精读笔记和匿名索引，不内嵌229篇语料池、论文PDF、赛题附件或培训课件。用户另行提供的合法资料应视为独立只读材料。笔记用于方法定位和风险提示，不能替代原文；核验引用、页码、公式或结论时必须读取当前实际可访问的合法材料。
