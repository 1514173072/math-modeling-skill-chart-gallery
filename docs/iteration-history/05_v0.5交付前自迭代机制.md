# v0.5｜交付前自迭代机制

## 工作流

题目与附件 → 条件问询并暂停 → 正式建模与写作 → 独立盲审 → 问题分级 → 定向返修 → 一致性复核 → 最终交付

## 复审重点

独立评审优先检查高风险问题：题意理解错误、关键附件遗漏、数据或标签泄漏、硬约束缺失、不可复现的数值、结论超过证据，以及引用或图表与正文不一致。

## 返修边界

- 只修改有证据支撑的问题；
- 不凭空补造实验、引用或数据；
- 若缺少关键材料，返回条件问询，而不是用默认值掩盖；
- 重大模型变更后重新检查上下文、公式、代码、图表和结论是否同步。

## 当前验证状态

当前交付版已经完成规则、模板和静态结构检查。你在加入新论文或修改规则后，仍应使用一套未参与改写的新题进行端到端验证，避免只在原案例上获得表面改进。
