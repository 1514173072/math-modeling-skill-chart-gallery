# 迭代5至7｜调用门与统计审计

## 主动调用与暂停门

仅仅“会调用Skill”仍不够。如果用户没有提前写清要求，Agent可能继续采用默认模板。因此加入强制规则：第一次调用后先列出已知条件与缺口，主动询问题目、附件、格式、篇幅、风格、重点、交付物和资源限制；关键答案缺失时停止正式建模。

## C题实战暴露的问题

一篇C题生成论文的自审得分为87.5，但独立评价约为71。差异主要来自：事件定义与题意语义可能错位、统计检验前提未被充分说明、训练与验证流程存在泄漏风险，以及部分结论超过证据强度。

## 转化为检查规则

- 先定义样本单位、标签、事件和时间窗口；
- 生存分析前说明删失机制与风险集；
- 使用log-rank等检验前确认适用条件；
- 数据预处理、特征选择和参数调优不得越过验证边界；
- 区分预测性能、相关关系、因果解释和真实干预效果。

这一阶段的核心结论是：格式完整和内部一致不能代替统计有效性。
