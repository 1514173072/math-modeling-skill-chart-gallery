# 数学建模 Skill 简版迭代日志

当前版本：v0.8.1

本 Skill 以历届优秀数学建模论文和多领域培训材料为基础，经过结构化阅读、方法提炼、真实赛题检验和多轮规则修订形成。开源版保留 33 篇匿名化结构化精读笔记，不附论文原文或培训课件。

## 版本变化

- **v0.1 基础流程**：建立审题、模型选择、代码、验证、论文写作和资料检索流程。
- **v0.2 方法与写作**：增强论文写作、探索性分析、动力系统、变分法、最优控制和弱识别优化。
- **v0.3 质量评价**：加入优秀论文基准思路，区分程序运行、数值复现和科学有效性。
- **v0.4 数据与验证**：增加主动前置问询、数据语义、纵向与生存分析、嵌套验证和关键数值复核。
- **v0.4.1 启动门**：条件未确认时必须暂停，避免直接套用默认模板。
- **v0.4.2 优化完整性**：增加硬约束、供需缺口、错误传播、并列解、选址、容量和定价检查。
- **v0.5 独立复审**：候选论文完成后先独立审阅，再从模型、代码和结果源头修复。
- **v0.6 多方法路由**：增加模糊与灰色方法、多属性决策、多元统计、随机过程、MCMC、随机规划和图网络。
- **v0.7 高级图表**：增加图表路由和证据契约，要求先有真实结果，再选择匹配模板。
- **v0.8 论文质量**：规范证据型扩写、通用章节、图表排布、语言、参考文献和源码交付。
- **v0.8.1 PDE 与空间建模**：增加偏微分方程数值求解、网格与残差验证、空间几何、合法路径和多模态空间评价。

迭代对象是 Skill 的指令、流程、检查规则和资料索引，不是对 GPT、GLM 等基础模型参数进行训练，也不代表能够保证获奖。
