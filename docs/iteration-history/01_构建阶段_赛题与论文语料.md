# 构建阶段｜赛题与论文语料

## 输入

- 2020—2025年A—F题，共36道赛题；
- 229篇已建立题号与年份索引的候选论文；
- 从中筛选75篇作为重点候选；
- 对33篇完成全文阅读与结构化审计，共覆盖约2094页。

## 处理方式

论文不是按“模型越复杂越好”排序，而是记录：题目如何拆解、每问采用什么模型、关键假设如何支撑、结果如何验证、图表如何服务结论、局限是否诚实。

阅读状态被明确区分：

- `indexed`：已建立年份、题号和文件索引；
- `screened`：已完成初步筛选；
- `full_read`：已完成全文阅读和结构化记录。

## 输出与边界

语料构建形成了方法导航和审计规则，但`full_read`不代表已经复现论文中的全部数据、代码或数值结果。这里的“训练”是对Skill指令、模板和评价框架的迭代，不是对基础模型进行参数微调。
