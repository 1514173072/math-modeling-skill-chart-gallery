# 图表库维度字典

> exe 启动时读本文件构建两个页签的类别列表；调整词表后 exe 点"刷新"即可生效，无需重新打包。
> 每张图在 frontmatter 的 `数据类型`、`方法类型` 各填**一个**值，取自下方词表。

## 数据类型（我手上是什么数据）

| 词 | 界定 |
|---|---|
| 单序列时序 | 一条时间索引 + 一个数值列（预测区间带也算） |
| 多序列时序 | 一条时间索引 + 多个数值列/分组 |
| 截面分组 | 无时间维或以截面为主：单元×数值，可带分组（模型对比、雷达、聚类散点等） |
| 二维矩阵 | 行×列两个有序类别维度 + 强度值（日历热力、相关矩阵等） |
| 地理与空间 | 有地理坐标/边界：面、点、线 |
| 网络与流向 | 节点+边，或分类列之间的流量（桑基、弦图、因果网络） |
| 文本与频次 | 词频、主题、情感占比等文本派生数据（词云、主题分布） |
| 示意与流程 | 无数据依赖的研究设计图：DAG、流程、决策地图 |

## 方法类型（我想干什么）

| 词 | 界定 |
|---|---|
| 描述概览 | 让读者快速看清结构与量级（总览、构成、流向） |
| 时序结构 | 展示趋势、周期、季节、变点 |
| 组间比较 | 组与组、模型与模型的对比 |
| 相关与滞后 | 相关性、滞后关系、交叉映射得分 |
| 因果识别 | 政策/处理效应：事件研究、DID、DML、CATE 异质性 |
| 因果发现 | 观测型因果边识别：CCM/RCM 收敛曲线、因果网络 |
| 模型评估 | 预测精度、区间覆盖、误差分解 |
| 稳健性与诊断 | 稳健性检验、敏感性、残差诊断 |
| 不平等与分布 | 分布形态、集中度（洛伦兹/基尼）、密度 |
| 多元统计 | 降维、载荷解释、聚类结构和多指标画像 |
| 优化与决策 | 可行域、权衡前沿、寻优过程、调度与方案选择 |
| 不确定性与风险 | 概率校准、尾部风险、机会约束和空间不确定性 |
| 模型解释 | 特征贡献、累积归因和局部解释路径 |
| 空间分析 | 空间格局、热点、冷点和局部不确定性 |
| 设计与流程 | 研究设计、样本构造、证据分层的示意表达 |
