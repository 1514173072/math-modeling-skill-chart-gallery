## 图表说明

把"证据怎么一层层变成决策"画成地图：每层一个色块，写清该层用什么数据、当前量化到哪一步、结论只允许用到哪里（如"观测方向不作 do 解释"）；底部箭头时间轴给出各层对应的时间节奏。适合答辩、汇报开场和研究框架交代。注意：块内文字多，改字后检查溢出；任何一层"失败退回诊断"的告诫保留在右下角红字。

```python
# -*- coding: utf-8 -*-
# 图表模板：证据门控分层决策地图
# 数据契约：无硬数据依赖；四层(层名,数据源,证据摘要,使用边界)+底部时间轴
# 协议：全中文标注；图内不加"XX图"标题；300dpi；末尾输出与笔记同名 PNG
import matplotlib as mpl
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "figure.dpi": 110, "savefig.dpi": 300, "savefig.bbox": "tight",
})

# ===== 1. 内容块（使用时替换为本研究的层名与数字） =====
blocks = [
    ("测量层", "原始记录与编码", "编码一致率 92.0%（n=2819）\n分语料分别建模", "只标记事实与主题", "#dbeafe", "#1d4ed8"),
    ("状态层", "阶段化状态面板", "可测状态单元 12000\n分窗构造", "短期激活不直接判为复苏", "#dcfce7", "#047857"),
    ("动力层", "观测因果发现", "晋级方向 14\n保留单向、双向与不支持", "用于监测优先级，不作 do 解释", "#fef3c7", "#b45309"),
    ("干预层", "目标试验 + 效应估计", "识别门：通过\n口径与效度需人工抽验", "区间与业务阈值共同决定资源门", "#ede9fe", "#6d28d9"),
]
timeline = ["发布后 0–3 周", "复盘 4–11 周", "检查 12–23 周", "继续 / 修复 / 停止"]

# ===== 2. 绘图 =====
fig, ax = plt.subplots(figsize=(13.0, 5.4))
ax.set_xlim(0, 13)
ax.set_ylim(0.35, 5.65)
ax.axis("off")
for index, (tier, source, evidence, action, fill, edge) in enumerate(blocks):
    x = 0.4 + index * 3.15
    ax.add_patch(FancyBboxPatch((x, 2.0), 2.65, 3.0,
                                boxstyle="round,pad=0.04,rounding_size=0.05",
                                facecolor=fill, edgecolor=edge, linewidth=1.4))
    ax.text(x + 0.18, 4.93, tier, fontsize=11, weight="bold", color=edge, va="top")
    ax.text(x + 0.18, 4.42, source, fontsize=10, weight="bold", va="top")
    ax.text(x + 0.18, 3.85, evidence, fontsize=8.7, va="top", linespacing=1.5)
    ax.text(x + 0.18, 2.42, action, fontsize=8.4, va="bottom", wrap=True)
    if index < len(blocks) - 1:
        ax.annotate("", xy=(x + 3.08, 3.65), xytext=(x + 2.69, 3.65),
                    arrowprops={"arrowstyle": "->", "color": "#475569", "lw": 1.4})
for i, (t, edge) in enumerate(zip(timeline, ["#1d4ed8", "#047857", "#b45309", "#6d28d9"])):
    ax.text(0.45 + i * 2.1, 1.25, t, color=edge, weight="bold", fontsize=9.5)
ax.annotate("", xy=(12.25, 1.15), xytext=(0.45, 1.15),
            arrowprops={"arrowstyle": "->", "color": "#64748b", "lw": 1.2})
ax.text(12.45, 0.55, "任何层级失败都退回诊断，不用更复杂模型覆盖失败门",
        ha="right", fontsize=8.5, color="#991b1b")

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("分层决策地图.png")
plt.close(fig)
print("已输出：分层决策地图.png")
```
