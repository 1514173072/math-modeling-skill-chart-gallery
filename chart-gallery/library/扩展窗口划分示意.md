## 图表说明

时序建模报告里"数据怎么切"的标准示意：每行一折，蓝色训练窗逐折扩展、浅蓝验证窗贴着右移，最后一折再接绿色测试段。读者据此核对三点——验证集是否始终在训练集之后、测试段是否只出现一次、各折窗口有无重叠。画法本身零数据依赖，论文方法节和实验设置节都好用。注意窗长参数要和正文写的一致，别示意归示意、实际归实际。

```python
# -*- coding: utf-8 -*-
# 图表模板：扩展窗口时序划分示意图（训练/验证/测试滚动条带）
# 数据契约：折数 + 初始训练窗长 + 验证窗长 + 测试窗长，横轴为统一时间索引
# 协议：全中文标注；图内不加"XX图"标题；Okabe-Ito 色板；300dpi；末尾输出与笔记同名 PNG

import matplotlib as mpl
import matplotlib.pyplot as plt
from matplotlib.patches import Patch

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9.5, "ytick.labelsize": 9.5, "legend.fontsize": 9.5,
    "axes.spines.top": False, "axes.spines.right": False,
    "axes.axisbelow": True, "figure.dpi": 110,
    "savefig.dpi": 300, "savefig.bbox": "tight", "legend.frameon": False,
})
OI = ["#0072B2", "#E69F00", "#009E73", "#D55E00", "#CC79A7", "#56B4E9", "#F0E442", "#999999"]
C_TRAIN, C_VAL, C_TEST = OI[0], OI[5], OI[2]

# ===== 1. 划分参数（使用时替换为真实折次设置） =====
n_folds = 6
train0, val_len, test_len = 24, 10, 12   # 初始训练窗、验证窗、测试窗长
step = 8                                  # 每折训练窗增量

rows = []
for i in range(n_folds):
    tr_end = train0 + step * i
    segs = [(0, tr_end, C_TRAIN)]
    segs.append((tr_end, val_len, C_VAL))
    if i == n_folds - 1:                  # 测试段只出现在最后一折
        segs.append((tr_end + val_len, test_len, C_TEST))
    rows.append(segs)
x_max = max(s[0] + s[1] for r in rows for s in r) + 2

# ===== 2. 绘图 =====
fig, ax = plt.subplots(figsize=(9.2, 4.4))
h = 0.62
for i, segs in enumerate(rows):
    y = n_folds - 1 - i                   # 第 1 折在最上行
    for start, width, cc in segs:
        ax.barh(y, width, left=start, height=h, color=cc,
                edgecolor="white", linewidth=1.1, zorder=3)
ax.set_yticks(range(n_folds), [f"第 {i+1} 折" for i in range(n_folds)])
ax.set_xlim(0, x_max)
ax.set_ylim(-0.6, n_folds - 0.4)
ax.set_xlabel("时间索引")
ax.grid(False)
ax.legend(handles=[Patch(color=C_TRAIN, label="训练"),
                   Patch(color=C_VAL, label="验证"),
                   Patch(color=C_TEST, label="测试")],
          loc="upper right", ncol=3)

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("扩展窗口划分示意.png")
plt.close(fig)
print("已输出：扩展窗口划分示意.png")
```
