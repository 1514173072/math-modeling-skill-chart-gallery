## 图表说明

滞后结构诊断的矩阵画法：横轴时滞 T-1 起步向右加深，纵轴特征逐行排开，颜色深浅=该特征在该滞后的权重/归因强度。正常形态是"底部近滞后行整体高亮、随滞后指数衰减"；若某特征在深滞后仍连片发亮（趋势项、季节项、远期日历效应），说明它携带长记忆，建模时值得保留更长窗口。与《剂量响应与滞后热图》互补——那张回答"处理在哪个滞后起效"，这张回答"哪些输入在哪段滞后携带信息"。注意重要性归一化方式（全局或按行）要写明，两种口径结论会差很多。

```python
# -*- coding: utf-8 -*-
# 图表模板：时滞×特征重要性热图（衰减矩阵）
# 数据契约：特征×时滞重要性矩阵（0–1）
# 协议：全中文标注；图内不加"XX图"标题；300dpi；末尾输出与笔记同名 PNG

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9, "ytick.labelsize": 9.5,
    "axes.spines.top": False, "axes.spines.right": False,
    "figure.dpi": 110, "savefig.dpi": 300, "savefig.bbox": "tight",
})

# ===== 1. 合成示例数据（使用时替换为真实的重要性矩阵） =====
rng = np.random.default_rng(7)
n_lag = 24
lags = np.arange(1, n_lag + 1)
feats = ["自身价格", "客流基线", "趋势项", "季节项", "节假日", "促销强度",
         "气温", "降水", "风速", "星期效应", "月末效应", "事件标记"]
tau = rng.uniform(3, 9, len(feats))
tau[2] = 20                                   # 趋势项：长记忆
W = np.column_stack([np.exp(-lags / t) for t in tau]).T
W[3] += 0.12 * (lags % 7 == 0)                # 季节项：周期亮点
W[4, 11] += 0.38                              # 节假日：深滞后亮点
W[10] += 0.15 * np.exp(-((lags - 5) ** 2) / 2)
W += rng.normal(0, 0.02, W.shape)
W = np.clip(W / W.max(), 0, 1)

# ===== 2. 绘图 =====
fig, ax = plt.subplots(figsize=(9.6, 5.6))
im = ax.imshow(W, aspect="auto", cmap="inferno", vmin=0, vmax=1)
marks = [1, 6, 12, 18, 24]                    # 地标滞后刻度，含末列
ax.set_xticks([l - 1 for l in marks], [f"T-{l}" for l in marks])
ax.set_yticks(range(len(feats)), feats)
ax.set_xlabel("输入时滞")
ax.grid(False)
cb = fig.colorbar(im, ax=ax, pad=0.015)
cb.set_label("重要性（归一化）")

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("时滞特征热图.png")
plt.close(fig)
print("已输出：时滞特征热图.png")
```
