## 图表说明

时空预测的成对对比版式：左区并排铺真值、参与方法的时空热图（共用色标），右区单独一张灰度误差热图——误差在哪片时空集中一望便知，避免"几幅图都挺像"的错觉。适合网格化时空序列（气象/场地/网格需求）的方法对比。注意：主图与误差图必须用不同 colormap（感知上分层）；色标范围统一为对比成立的前提。

```python
# -*- coding: utf-8 -*-
# 图表模板：时空热图对比 + 误差热图（成对布局）
# 数据契约：时空场矩阵多份（真值+预报），误差场=预报−真值
# 协议：全中文标注；图内不加"XX图"标题；300dpi；末尾输出与笔记同名 PNG
import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9, "ytick.labelsize": 9,
    "figure.dpi": 110, "savefig.dpi": 300, "savefig.bbox": "tight",
})

# ===== 1. 合成示例数据（使用时替换为真实时空场） =====
rng = np.random.default_rng(7)
S, T = 30, 80
x = np.linspace(0, 1, S)[:, None]
t = np.linspace(0, 1, T)[None, :]
truth = np.sin(3 * np.pi * x) * np.cos(2 * np.pi * t) + 0.3 * np.sin(6 * np.pi * x * t)
ens = [truth + rng.normal(0, 0.10, (S, T)) for _ in range(20)]
member = ens[0]
mean = np.mean(ens, axis=0)
err = np.abs(mean - truth)
vmax = np.abs(truth).max()

# ===== 2. 绘图 =====
fig = plt.figure(figsize=(13, 4.6))
gs = fig.add_gridspec(1, 4, width_ratios=[1, 1, 1, 1.1], wspace=0.30)
panels = [("真值", truth, "cividis", None), ("单个集合成员", member, "cividis", None),
          ("集合均值", mean, "cividis", None), ("误差 |均值−真值|", err, "Greys", None)]
for k, (name, mat, cm, _) in enumerate(panels):
    ax = fig.add_subplot(gs[0, k])
    im = ax.imshow(mat, aspect="auto", cmap=cm, vmin=-vmax if k < 3 else 0,
                   vmax=vmax if k < 3 else err.max())
    ax.set_title(name, fontsize=10.5)
    ax.set_xlabel("时间步" if k > 0 else "")
    if k == 0:
        ax.set_ylabel("空间格点")
        ax.set_xlabel("时间步")
    cb = fig.colorbar(im, ax=ax, shrink=0.85)
    cb.ax.tick_params(labelsize=8)

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("时空热图与误差.png")
plt.close(fig)
print("已输出：时空热图与误差.png")
```
