## 图表说明

异质性效应的轻量展示：按调节变量分箱后展示各箱效应及区间。点之间默认不连线，避免把离散分箱误读为连续响应曲线。分箱边界、样本量和区间算法必须在正文交代；若估计量在对数尺度上拟合，应先在模型侧正确变换区间，再把 lo/hi 交给绘图模板。

```python
# -*- coding: utf-8 -*-
# 图表模板：分箱异质性效应点区间（CATE 按分位组）
# 数据契约：每组 x、estimate、lo、hi、n；绘图层不自行猜测标准误尺度
# 协议：全中文标注；图内不加"XX图"标题；Okabe-Ito 色板；300dpi；末尾输出与笔记同名 PNG
import matplotlib as mpl
import matplotlib.pyplot as plt
import pandas as pd

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9.5, "ytick.labelsize": 9.5, "legend.fontsize": 9.5,
    "axes.spines.top": False, "axes.spines.right": False,
    "axes.grid": True, "grid.color": "#D9D9D9", "grid.linewidth": 0.6,
    "axes.axisbelow": True, "figure.dpi": 110,
    "savefig.dpi": 300, "savefig.bbox": "tight", "legend.frameon": False,
})
C_MAIN = "#0072B2"

# ===== 1. 合成示例数据（使用时替换为真实估计输出） =====
binned = pd.DataFrame({
    "x": [0.9, 1.3, 1.7, 2.1, 2.6],
    "estimate": [0.42, 0.47, 0.50, 0.55, 0.61],
    "lo": [0.35, 0.40, 0.43, 0.46, 0.50],
    "hi": [0.51, 0.55, 0.58, 0.66, 0.74],
    "n": [118, 121, 119, 120, 122],
})

# ===== 2. 绘图 =====
fig, ax = plt.subplots(figsize=(7.8, 4.8))
err = [binned["estimate"] - binned["lo"], binned["hi"] - binned["estimate"]]
ax.errorbar(binned["x"], binned["estimate"], yerr=err, fmt="o", ms=7, color=C_MAIN,
            ecolor="#BBC7D6", elinewidth=1.8, capsize=3)
ax.axhline(1.0, color="#999", lw=0.9, ls="--")
ax.set_ylim(0.32, 1.12)
for _, r in binned.iterrows():
    ax.annotate(f"{r['estimate']:.2f}\nn={int(r['n'])}", (r["x"], r["estimate"]),
                textcoords="offset points", xytext=(7, 7), fontsize=8.5, color="#444")
ax.set_xlabel("调节变量（分位组均值）")
ax.set_ylabel("效应比 IRR（分箱回归，95% CI）")

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("分箱效应曲线.png")
plt.close(fig)
print("已输出：分箱效应曲线.png")
```
