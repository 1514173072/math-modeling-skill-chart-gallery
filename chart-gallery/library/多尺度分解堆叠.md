## 图表说明

多尺度分解（STL、多周期分解、小波多分辨皆可套）的标准呈现：每行一个分量、共享横轴，读者纵向对照即可看出"2022 年那波尖峰是半年趋势贡献的、波动项同步放大"这类结构结论。库内时序结构类此前只有单面板形态，堆叠面板是空位。要点：各行 y 轴量纲不同，不要共享 y 轴；波动项行建议画 0 基准线；若做预测对比，可在每行叠 Actual 实线与 Predicted 虚线。

```python
# -*- coding: utf-8 -*-
# 图表模板：多尺度时序分解堆叠面板（共享横轴）
# 数据契约：等间隔时间索引 + 长度对齐的分量序列（趋势/周期/残差）
# 协议：全中文标注；图内不加"XX图"标题；Okabe-Ito 色板；300dpi；末尾输出与笔记同名 PNG

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9.5, "ytick.labelsize": 9.5,
    "axes.spines.top": False, "axes.spines.right": False,
    "axes.grid": True, "grid.color": "#D9D9D9", "grid.linewidth": 0.6,
    "axes.axisbelow": True, "figure.dpi": 110,
    "savefig.dpi": 300, "savefig.bbox": "tight",
})
OI = ["#0072B2", "#E69F00", "#009E73", "#D55E00", "#CC79A7", "#56B4E9", "#F0E442", "#999999"]

# ===== 1. 合成示例数据（使用时替换为真实分解结果） =====
rng = np.random.default_rng(21)
idx = pd.date_range("2022-01-01", "2023-06-30", freq="D")   # 18 个月窗口，保证月度周期可辨
t = np.arange(len(idx))
trend_semi = 2.2 * np.sin(2 * np.pi * t / 183 + 0.4) + 0.8 * np.sin(2 * np.pi * t / 365)
season_q = 1.1 * np.sin(2 * np.pi * t / 91)
season_m = 0.45 * np.sin(2 * np.pi * t / 30 + 1.1)
resid = rng.normal(0, 0.22, len(t))
rows = [
    ("原序列", trend_semi + season_q + season_m + resid, OI[0]),
    ("半年趋势", trend_semi, OI[3]),
    ("季度周期", season_q, OI[1]),
    ("月度周期", season_m, OI[2]),
    ("波动项", resid, OI[7]),
]

# ===== 2. 绘图（共享横轴的堆叠面板） =====
fig, axes = plt.subplots(len(rows), 1, sharex=True, figsize=(9.4, 7.4))
for ax, (name, y, cc) in zip(axes, rows):
    ax.plot(idx, y, color=cc, lw=1.1)
    ax.set_ylabel(name)
    if name == "波动项":
        ax.axhline(0, color="#6B6B6B", ls="--", lw=0.8)
axes[-1].set_xlabel("日期")
fig.align_ylabels(axes)

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("多尺度分解堆叠.png")
plt.close(fig)
print("已输出：多尺度分解堆叠.png")
```
