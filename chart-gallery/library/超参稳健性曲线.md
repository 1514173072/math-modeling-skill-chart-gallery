## 图表说明

模型选择证据的标准画法：横轴超参（K）、纵轴归一化得分，实线为多种子均值、浅带为种子间波动——带宽大说明该点结果不稳，最优点只有落在"峰值+窄带"处才算硬。两条指标（如 u_mass 与 c_v 一致性）归一化后同图，最优点重合才敢定 K。适合 LDA 主题数、聚类 K、树深等一切"选超参"场景。注意：归一化方法要写进说明；带宽用 min–max 或分位带并注明。

```python
# -*- coding: utf-8 -*-
# 图表模板：超参选择稳健性曲线（多指标 + 多种子带）
# 数据契约：超参网格×指标×多种子的得分长表；各指标归一化后同图
# 协议：全中文标注；图内不加"XX图"标题；300dpi；末尾输出与笔记同名 PNG
import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", "SimHei"],
    "axes.unicode_minus": False,
    "font.size": 10.5, "axes.labelsize": 10.5,
    "xtick.labelsize": 9.5, "ytick.labelsize": 9.5, "legend.fontsize": 9.5,
    "axes.spines.top": False, "axes.spines.right": False,
    "axes.grid": True, "grid.color": "#D9D9D9", "grid.linewidth": 0.6,
    "axes.axisbelow": True, "figure.dpi": 110,
    "savefig.dpi": 300, "savefig.bbox": "tight", "legend.frameon": False,
})
OI = ["#0072B2", "#E69F00", "#009E73", "#D55E00", "#CC79A7", "#56B4E9", "#F0E442", "#999999"]

# ===== 1. 合成示例数据（使用时替换为真实评分长表） =====
rng = np.random.default_rng(12)
ks = np.arange(2, 11)
seeds = np.arange(5)
raw = {"一致性 A": {}, "一致性 B": {}}
for m in raw:
    peak = 6 if m == "一致性 A" else 7
    raw[m] = {k: [np.exp(-((k - peak) ** 2) / 6) + rng.normal(0, 0.03)
                  for _ in seeds] for k in ks}

def norm(v):
    v = np.asarray(v, dtype=float)
    return (v - v.min()) / (v.max() - v.min())

# ===== 2. 绘图 =====
fig, ax = plt.subplots(figsize=(9.4, 4.8))
for (m, table), cc in zip(raw.items(), OI):
    mean = norm([np.mean(table[k]) for k in ks])
    lo = norm([np.min(table[k]) for k in ks])
    hi = norm([np.max(table[k]) for k in ks])
    ax.plot(ks, mean, "-o", color=cc, lw=2, ms=5, label=m)
    ax.fill_between(ks, lo, hi, color=cc, alpha=0.14)
k_best = 6
ax.axvline(k_best, color="#D55E00", ls="--", lw=1.2)
ax.text(k_best + 0.08, 0.08, f"选定 K={k_best}", color="#D55E00", fontsize=9.5)
ax.set_xticks(list(ks))
ax.set_xlabel("主题数 K（超参）")
ax.set_ylabel("归一化得分（多种子）")
ax.legend(loc="upper left")

# ===== 3. 输出（文件名必须与笔记同名） =====
fig.savefig("超参稳健性曲线.png")
plt.close(fig)
print("已输出：超参稳健性曲线.png")
```
